Question 4 Back Part New Site Design Notes

一、问题理解

问题四后半部分要求在问题一预测结果基础上，讨论新增物流场地及线路的设计方案，包括新增场地应与哪些已有场地连接、新增线路方向与能力如何设置、新增场地处理能力如何设置，并考虑预测结果随机性下的网络鲁棒性。

本问将前半题的重要性评价结果作为主依据，同时在新增连接对象中补充高负荷风险区域。需要注意：负荷率不参与重要性评分，但可以用于新增能力设计和风险区域识别。

二、设计原则

新增场地记为 DC_NEW。

设计原则如下：

1. 连接核心重要场地

优先覆盖货量规模大、连接广、失效影响大的核心场地，使 DC_NEW 接入网络主干。

2. 覆盖风险瓶颈场地

部分场地虽然综合重要性不最高，但预测期接近能力上限，存在运行风险，应通过新增线路提供缓冲能力。

3. 根据货流方向设置有向线路

题目中线路是有向的，因此不默认全部双向连接。先根据预测入货量和出货量判断场地角色，再决定新增线路方向。

4. 针对超载线路补齐分流路径

如果某条预测线路已经超过历史运输能力，则新增场地应尽可能为该线路提供 i -> DC_NEW -> j 的替代通道。因此，在基础有向线路之外，对预测超载线路补齐必要方向。

5. 保留能力冗余

考虑预测结果随机性，新增场地和新增线路能力不只服务基准预测，也要在 10% 至 15% 随机扰动下保持一定稳定性。

三、场地角色识别

对候选场地 k，计算 2023 年 1 月预测入货量和出货量：

In_k = sum_t sum_i q_{i,k,t}

Out_k = sum_t sum_j q_{k,j,t}

总处理量为：

T_k = In_k + Out_k

定义：

入货占比 = In_k / T_k

出货占比 = Out_k / T_k

若出货占比 >= 0.6，则定义为输出型场地；

若入货占比 >= 0.6，则定义为输入型场地；

否则定义为中转型场地。

新增线路方向规则为：

输出型场地：新增 k -> DC_NEW；

输入型场地：新增 DC_NEW -> k；

中转型场地：新增 k -> DC_NEW 和 DC_NEW -> k。

六、新增线路能力设置

设已有线路运输能力最大值为：

C_max = 505833

对每个连接场地 k，记其预测日处理量峰值为 P_k。新增线路能力按以下规则设置：

C = min(C_max, max(100000, 0.55 P_k))

并向上取整到千位。

该规则含义为：

1. 大型核心场地获得更高新增线路能力；
2. 中小型或风险场地至少获得 100000 的基础分流能力；
3. 新增线路能力不超过现有线路能力最大值，满足题目要求。

八、新增结构使用方式

对于同时满足以下条件的关键线路：

1. 起点和终点均属于 DC_NEW 的连接场地；
2. 线路属于重要线路集合；
3. 存在起点到 DC_NEW 和 DC_NEW 到终点的有向新增线路；

则允许将部分货量由：

i -> j

调整为：

i -> DC_NEW -> j

本次模拟中，对重要线路最多分流 20% 预测货量，并受新增线路能力和新增场地处理能力约束。

九、鲁棒性分析方法

考虑预测结果随机性，本问设置三类场景：

1. 基准预测；
2. 10% 随机扰动；
3. 15% 随机扰动。

随机扰动场景下，对每条线路预测货量乘以随机扰动系数，并将扰动系数限制在合理范围内。每种随机扰动场景进行 200 次模拟。

比较新增结构前后：

线路超载记录数；

线路超载总量；

线路负荷率标准差；

线路负荷率变异系数；

新增场地最大负荷率。

十一、结论

按货流方向设置基础有向新增线路，并针对预测超载线路补齐必要方向后，新增线路数为 16 条。该方案比全部双向连接更经济，又能主动处理基准预测中的超载线路。

该方案在基准预测下将线路超载记录数由 15 降至 8，将超载总量由 42203 降至 17385。在 10% 和 15% 随机扰动下，也能显著降低平均超载记录数和超载总量。同时 DC_NEW 最大负荷率约为 0.55，仍保留了充分处理能力冗余。

因此，最终建议采用“核心/风险场地定向连接 + 超载线路补线”的新增结构方案。

十二、方案合理性说明

1. 为什么不是全部双向连接

如果对所有连接场地都设置双向线路，网络冗余会更强，但新增线路数量会显著增加。由于题目中的线路是有向线路，全部双向连接会引入部分与主要货流方向不一致的线路，建设成本较高，也不够贴合货流结构。

本方案先根据场地角色设置基础有向线路：

输出型场地设置 k -> DC_NEW；

输入型场地设置 DC_NEW -> k；

中转型场地才设置双向线路。

在此基础上，仅对预测超载线路补齐必要方向，使超载线路能够通过 i -> DC_NEW -> j 分流。最终新增 16 条有向线路，而不是对 14 个连接场地全部双向开设 28 条线路。这样既减少了新增线路数量，又能覆盖关键超载路径。

2. 为什么需要补充超载线路方向

仅按场地角色开线时，部分预测超载线路无法通过 DC_NEW 分流。例如若线路 DC9->DC3 超载，要通过新增场地分流，必须存在：

DC9->DC_NEW

DC_NEW->DC3

因此，本方案在角色线路之外补充 DC9->DC_NEW 和 DC_NEW->DC14 等必要方向，使新增场地不仅连接核心场地，还能够实际缓解基准预测中的超载线路。

3. 改善率说明

基准预测场景下：

线路超载记录减少率 = (15 - 8) / 15 = 46.67%

线路超载总量减少率 = (42203 - 17385) / 42203 = 58.81%

线路负荷率标准差下降率 = 7.17%

10% 随机扰动场景下：

平均线路超载记录减少率 = 42.47%

平均线路超载总量减少率 = 56.43%

线路负荷率标准差下降率 = 7.16%

15% 随机扰动场景下：

平均线路超载记录减少率 = 36.13%

平均线路超载总量减少率 = 54.40%

线路负荷率标准差下降率 = 7.14%

可以看出，新增结构在基准预测和随机扰动场景下均能稳定降低超载规模，并改善线路负荷分布。

4. 为什么新增场地能力为 800000

在基准、10%扰动和15%扰动场景下，DC_NEW 最大负荷率约为 0.55，说明处理能力仍有充足冗余。该设置既能满足新增场地作为缓冲节点的需求，又避免能力设置过低导致预测扰动下再次成为瓶颈。

5. 方案定位

本方案是建设成本和鲁棒性之间的折中：

相比单纯按角色开线，补充超载路径后能显著降低超载；

相比全部双向连接，新增线路数量更少，更符合有向货流特征；

相比直接扩容原有场地，新增 DC_NEW 能作为网络缓冲节点，提升整体结构鲁棒性。
