# Question 3 File Guide

This folder contains the initial analysis for Project 2, Problem B,
Question 3.

## Folder Layout

- `docs/`: modeling notes and writing guidance.
- `results/`: candidate task tables derived from the Question 2 practical
  MILP results.

## Current Files

- `docs/analysis-notes.txt`: initial modeling route for bundled task release.
- `code/bundle-simulation.py`: forms initial short-distance bundles and
  compares bundled release with the Question 2 practical MILP baseline.
- `results/bundle-candidate-tasks.csv`: tasks that remain low-probability
  after Question 2 and hit the maximum price-adjustment boundary.
- `results/bundle-candidate-summary.csv`: regional summary of the candidate
  bundled-task set.
- `results/bundle-package-results.csv`: package-level bundled-release
  simulation results.
- `results/bundle-comparison.csv`: overall comparison with the Question 2
  practical MILP baseline.
- `results/bundle-regional-summary.csv`: regional bundled-task gains.
- `figures/bundle-comparison.png`: first comparison chart for bundled release.
