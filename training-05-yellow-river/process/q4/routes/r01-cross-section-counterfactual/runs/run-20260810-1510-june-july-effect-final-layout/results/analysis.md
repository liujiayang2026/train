# PCHIP口径下2020—2022年6—7月前后河床效果

## 1. 内部稳健区总体效果

为降低岸坡端点和水边线变化的放大作用，主解释采用1725—2050 m内部稳健区，完整共同覆盖区结果保留在同一CSV中。

从4月基线到7月末，三年均为净淤积：

- 2020年：淤积83.13 m²、冲刷10.94 m²，净变化+72.19 m²；
- 2021年：淤积130.93 m²、冲刷38.87 m²，净变化+92.06 m²；
- 2022年：淤积46.89 m²、冲刷15.92 m²，净变化+30.97 m²。

但从7月首测到7月末测，年度差异明显：

- 2020年：净淤积+35.88 m²；
- 2021年：净淤积+102.43 m²，冲刷面积在数值精度下近似为0；
- 2022年：净冲刷−169.90 m²，内部稳健区几乎全区冲刷。

因此“4月至7月累计变化”和“7月事件内部变化”不能互相替代。2022年4月至7月仍为净淤积，但7月7日至23日发生了足以逆转近期趋势的强冲刷。

## 2. 主槽2005—2040 m

在此前识别的主槽高响应区2005—2040 m，7月首末测次平均高程变化分别为：

- 2020年：+0.32 m，区间净断面变化+12.09 m²，表现为淤积；
- 2021年：+0.58 m，区间净断面变化+21.14 m²，表现为更强淤积；
- 2022年：−0.86 m，区间净断面变化−30.56 m²，表现为强冲刷，最大局部冲刷约0.95 m，位于2025 m附近。

这证明主槽变化是明显的，但调水调沙时期并非固定产生冲刷：2020、2021年该断面出现泥沙落淤或断面回填，2022年则出现显著下切。

## 3. 三附件证据关系

附件1显示，2020年6月底至7月上旬出现高流量过程，7月10—15日及26—31日出现高含沙过程；2021年6月底至7月初出现高流量过程，7月7—9日及22日前后出现含沙量峰值。附件3测次与这些水沙过程较好对齐，支持把2020、2021年的断面变化解释为调水调沙时期的河床响应。附件1缺少2022年，故2022年只能确认7月断面强冲刷，不能用同一水沙指标完成驱动归因。

附件2的2019年4月13日至10月15日全断面对比表明，附件3覆盖区位于全断面主要深槽内；但该测次间隔还包含8—10月变化，所以只作为空间背景，不作为2020—2022年度效果估计。

## 4. 当前结论边界

所有连续断面和面积指标均以PCHIP为主口径，5 m仅是计算网格。当前结果是有水沙过程支持的描述性前后效果，不是带同期未调度对照的严格因果效应。后续应将附件1的累计水量、累计输沙量和峰值时序定量连接到各年冲淤差异。
