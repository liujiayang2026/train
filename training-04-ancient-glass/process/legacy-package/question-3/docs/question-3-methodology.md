# 问题三建模思路

## 1. 题目要求

问题三要求对附件表单 3 中未知类别玻璃文物的化学成分进行分析，鉴别其所属类型，并对分类结果进行敏感性分析。

问题三直接承接问题二：问题二已经建立了高钾玻璃与铅钡玻璃的大类分类规则，并给出了各大类内部的亚类中心。因此，问题三不重新构造分类标准，而是将表单 3 的未知样本投影到问题二建立的分类空间中。

整体路线为：

\[
\boxed{
\text{未知样本有效性检查}
\rightarrow
\text{大类判别}
\rightarrow
\text{风化条件修正验证}
\rightarrow
\text{亚类归属}
\rightarrow
\text{敏感性分析}
}
\]

## 2. 数据预处理

表单 3 中共有 8 件未知文物，记为 A1--A8。空白成分仍按未检测到处理，记为 0。对每个样本计算成分总和：

\[
S_i=\sum_{j=1}^{14}x_{ij}.
\]

8 件未知文物的成分总和均位于 85%--105% 的有效范围内，因此全部保留。随后对成分进行闭合归一化，使其总和为 100%。

## 3. 大类判别方法

沿用问题二的大类判别指标：

\[
R_i=\ln\frac{PbO_i+BaO_i+\varepsilon}{K_2O_i+\varepsilon}.
\]

其中 \(\varepsilon=0.1\)。若 \(R_i\) 大于问题二在已知样本上确定的阈值，则判为铅钡玻璃；否则判为高钾玻璃。

同时使用问题二中的 CLR 最近中心模型复核分类结果。若阈值规则和最近中心模型一致，则认为大类判别结果较稳定。

## 4. 风化样本的条件修正

表单 3 中 A2、A5、A6、A7 标记为风化。由于风化会改变化学成分，问题三对这些样本增加风化条件修正验证。

对每个风化未知样本，分别假设其为高钾或铅钡玻璃，并使用问题一对应类型的 CLR 风化效应进行反向修正：

\[
\hat y_{ij}^{(U)}=y_{ij}^{(W)}-d_{tj},
\]

其中 \(d_{tj}\) 为问题一估计的类型 \(t\) 下成分 \(j\) 的风化效应。修正后再重新进行大类判别。

若原始判别和条件修正判别的大类一致，说明大类结果对风化修正稳定；若亚类发生变化，则只将亚类作为辅助判断。

## 5. 亚类归属方法

在确定大类后，将未知样本与问题二得到的亚类中心比较。比较时使用相应大类的候选成分：

- 高钾玻璃：\(SiO_2,K_2O,CaO,MgO,Al_2O_3,Fe_2O_3,CuO\)；
- 铅钡玻璃：\(SiO_2,PbO,BaO,P_2O_5,SrO,CuO\)。

对候选成分进行 CLR 变换和标准化，计算未知样本到各亚类中心的欧氏距离，距离最小的亚类作为其亚类归属。

## 6. 敏感性分析

敏感性分析主要考察两个方面：

1. 改变 CLR 伪计数 \(\varepsilon=0.05,0.10,0.50\)，重复阈值判别和最近中心判别；
2. 对风化样本分别使用高钾、铅钡两种类型条件修正，观察大类结论是否改变。

若所有伪计数下阈值模型与最近中心模型均给出相同大类，则认为大类鉴别稳定。

## 7. 结果解释原则

问题三中大类鉴别作为主要结论，亚类归属作为辅助结论。若某个样本的大类在原始数据、风化修正和伪计数敏感性下均不变，则可给出较高置信度。若大类稳定但亚类随风化修正变化，则论文中应写为“所属大类稳定，亚类判断存在一定不确定性”。
