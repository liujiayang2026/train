# Route r05-cost-constrained-sampling

- 对应问题：q3
- 过程状态：candidate
- 要回答的内容：在 `r04-monthly-flux-forecast` 的 2022—2023 月度预测与风险信息基础上，给出带显式资源成本目标、重构误差约束、突变捕获约束和现场动态触发协议的采样方案，并与等间隔、旧启发式及关闭动态触发的同间隔消融方案比较。
- 输入与数据口径：代码通过 CLI 分别接收 q2 `daily_flux_series.csv`、`abrupt_change_events.csv`、`abrupt_event_stability.csv`，以及 r04 `monthly_forecast_2022_2023.csv`、`monthly_sampling_strategy.csv`、`sampling_schedule_2022_2023.csv`。默认路径只用于开发复核；形成新运行时必须在 `run.md` 和命令中显式传入所采用的六个文件。2018—2020 用于 r05 策略校准与优化；2021 只作为“策略层条件留出”回放。由于上游 q1 补全和 r04 风险构造可能使用全时段信息，不把 2021 声称为端到端无泄漏留出。
- 核心模型/算法：用相邻月份阈值转移型混合整数线性规划选择“基础采样间隔 + 上月阈值 + 本月动态触发阈值”，最小化年度平均出勤与化验资源成本；流守恒约束使 12 个月首尾相接。现场每天 09:00 使用截至当时的瞬时流量 `Q` 和快速浊度/含沙代理 `C` 构造同刻 `Q` 与 `Q*C` 代理；达到来源日所属月份的阈值后，在后两个日历日各加采一次，跨月、跨年不重置，重复日期合并。策略和基线的事件 ±1 日命中在每个验证切分合并后的全局采样日历上统一评分。硬约束包括两类代理重构 WAPE、突变事件捕获率和风险等级对应的最大基础间隔。
- 关键公式位置：`model/method.md`；预测与采样一体化的完整解题链见 `model/complete-solution.md`
- 代码入口：`code/cost_constrained_sampling.py`
- 关联运行：`runs/run-20260809-2145-global-event-boundaries/` 为当前显式绑定 q2 2036 与 r04 2103 的成功候选证据，动态日历和事件评分均跨月连续，28/28 质量检查和 9/9 单元测试通过。`runs/run-20260809-2124-continuous-calendar-boundaries/` 已修复动态状态与动作，但两条描述性基线仍未跨月评分事件；2105 与 2046 还存在按月重置动态判定、遗漏跨月加采的缺陷；1955 是旧输入和旧验证口径下的成功历史运行，1941 为输入字段假设错误的失败运行。上述运行均保留，当前成功 run 也不等于人工 adopted 决定。
- 与其他问题/路线的关系：继承 r04 的未来月度预测、风险等级和旧采样表，不重新选择或重估预测模型；q2 日序列仅作为监测设计的历史代理，q2 事件稳定性表用于给捕获率加上参数稳健性权重。不会把 q1 补值或 q2 插值序列解释为新增真实观测。
- 当前优点：成本、误差、事件捕获、最大基础间隔和现场触发协议均显式化；相邻月阈值转移和完整日历回放覆盖月初比较、月末触发、跨年动作及跨月事件窗口；报告同基础间隔动态消融；输出网格化 ε-约束近似非支配集、事件稳定性加权捕获率、精确小样本边界和多组成本系数下的节约率；输入和代码哈希写入日志与 manifest。
