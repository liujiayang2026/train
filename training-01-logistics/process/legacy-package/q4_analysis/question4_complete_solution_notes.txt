一、问题理解

问题四包含两部分：

1. 根据附件1，对物流网络中不同物流场地及线路的重要性进行评价；
2. 为改善网络性能，结合问题一预测结果，讨论新增物流场地及线路的设计，并分析网络鲁棒性。

本问将“重要性评价”和“风险压力分析”区分开来。重要性评价主要衡量场地或线路在网络中的业务规模、连接结构、失效影响和替代性；负荷率主要反映运行压力，不纳入重要性综合得分，但在新增场地和线路设计中作为识别风险瓶颈和超载线路的辅助依据。

三、场地处理量口径

对场地 k 和日期 t，场地处理量定义为：

B_{k,t} = In_{k,t} + Out_{k,t}

其中：

In_{k,t} = sum_i q_{i,k,t}

Out_{k,t} = sum_j q_{k,j,t}

即场地处理量等于该场地当日入货量与出货量之和。

四、场地重要性评价

场地重要性使用四类主指标。

1. 货量规模指标

包括历史总处理量和预测总处理量。由于历史数据中存在长期停运、临时异常和数据空白，货量规模得分提高预测权重：

VolumeScore = 0.75 * rank(预测总处理量) + 0.25 * rank(历史总处理量)

2. 连接结构指标

包括入度、出度和总度数。连接越广，说明该场地在网络结构中越关键：

StructureScore = rank(总度数)

3. 波动影响指标

使用预测日处理量变异系数：

CV_k = std(B_{k,t}) / mean(B_{k,t})

波动越大，说明场地调度不确定性越强。

4. 失效直接影响指标

若场地 k 关停，则所有与 k 直接相连的预测货量都会受到影响。因此直接影响货量取预测总处理量：

DirectImpact_k = sum_t B_{k,t}

五、场地综合得分

各指标做百分位归一化后，场地综合得分为：

SiteScore =
0.35 * VolumeScore
+ 0.25 * StructureScore
+ 0.15 * VolatilityScore
+ 0.25 * FailureImpactScore

该得分强调场地货量规模、连接结构和失效影响，不包含负荷率。

六、线路重要性评价

线路重要性使用四类主指标。

1. 货量规模指标

包括历史总货量和预测总货量。考虑历史异常影响，线路货量规模得分为：

VolumeScore = 0.75 * rank(预测总货量) + 0.25 * rank(历史总货量)

2. 端点重要性指标

线路 i->j 的结构价值与起点和终点场地重要性有关：

EndpointScore_{ij} = 0.5 * SiteScore_i + 0.5 * SiteScore_j

ConnectionScore = rank(EndpointScore_{ij})

3. 波动影响指标

使用预测日货量变异系数：

CV_{ij} = std(q_{ij,t}) / mean(q_{ij,t})

4. 替代性风险指标

对线路 i->j，计算除该线路外，同起点其他线路和同终点其他线路的运输能力之和：

AltCap_{ij} = same_origin_alternative_capacity + same_dest_alternative_capacity

替代能力越弱，该线路越不可替代：

SubstitutionRiskScore = rank(- AltCap_{ij} / C_{ij})

各指标做百分位归一化后，线路综合得分为：

EdgeScore =

+ 0.25 * SubstitutionRiskScore

八、新增场地设计原则

新增场地记为 DC_NEW。

新增结构设计遵循以下原则：

1. 连接核心重要场地；
2. 覆盖高失效影响场地的关键上下游；
3. 覆盖预测期存在风险的区域；
4. 根据货流方向设置有向线路；
5. 对预测超载线路补齐必要分流路径；
6. 保留能力冗余，应对预测随机性。

九、候选场地角色识别

对候选场地 k，计算预测入货量和出货量：

In_k = sum_t sum_i q_{i,k,t}

Out_k = sum_t sum_j q_{k,j,t}

T_k = In_k + Out_k

入货占比 = In_k / T_k

出货占比 = Out_k / T_k

若出货占比 >= 0.6，则定义为输出型场地；

若入货占比 >= 0.6，则定义为输入型场地；

否则定义为中转型场地。

新增线路方向规则为：

输出型场地：k -> DC_NEW；

输入型场地：DC_NEW -> k；

中转型场地：双向连接。

十六、方案合理性

1. 为什么不是全部双向连接

全部双向连接会提供更强冗余，但会显著增加新增线路数量。由于线路是有向的，全部双向连接会引入部分与主要货流方向不一致的线路，建设成本较高。本方案按场地角色设置基础有向线路，并只对超载线路补齐必要方向，最终新增 16 条线路，而不是对 14 个连接场地全部双向开设 28 条线路。

2. 为什么需要补充超载路径

仅按场地角色开线时，部分预测超载线路无法经 DC_NEW 分流。例如 DC9->DC3 若要分流，需要 DC9->DC_NEW 和 DC_NEW->DC3。因此，本方案在基础线路之外补充 DC9->DC_NEW 和 DC_NEW->DC14 等方向，使新增场地能够实际缓解预测超载线路。

十七、结论

本问首先基于货量规模、连接结构、波动影响和失效直接影响评价场地重要性，基于货量规模、端点重要性、波动影响和替代性风险评价线路重要性。随后结合重要性评价和预测风险，设计新增场地 DC_NEW。

最终建议 DC_NEW 连接 14 个已有场地，新增 16 条有向线路，处理能力设置为 800000。该方案兼顾核心节点覆盖、高失效影响区域覆盖、预测超载线路缓解和建设成本控制。鲁棒性模拟表明，新增结构能够明显降低超载记录和超载总量，并降低线路负荷率标准差，说明网络性能和鲁棒性得到改善。
