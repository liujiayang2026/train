# 问题二建模思路

## 1. 题目要求与总体路线

问题二需要在已分类玻璃文物的基础上完成三项任务：

1. 分析高钾玻璃与铅钡玻璃的分类规律；
2. 对每个大类选择合适的化学成分进行亚类划分，并给出具体划分方法和结果；
3. 对分类结果的合理性和敏感性进行分析。

问题一已经表明风化会显著改变化学成分，因此问题二不能简单混用风化点和无风化点的原始成分。整体建模路线为：

\[
\boxed{
\text{构造风化修正数据}
\rightarrow
\text{大类分类规律分析}
\rightarrow
\text{分类判别模型}
\rightarrow
\text{分类型亚类划分}
\rightarrow
\text{合理性与敏感性检验}
}
\]

其中，大类分类强调“高钾--铅钡”的可解释判别规律；亚类划分强调在每个大类内部寻找具有化学意义的细分结构。

## 2. 数据构造与预处理

### 2.1 分析对象

问题二使用附件表单 1 和表单 2 中已知类别的文物样本。表单 1 给出文物的大类标签，表单 2 给出各采样点的化学成分比例。

仍按题目要求，仅保留成分总和在 85% 到 105% 之间的有效采样点。空白成分表示未检测到，记为 0。

### 2.2 风化修正数据

由于风化会改变成分比例，主分析使用问题一得到的风化前修正数据：

- 无风化采样点：使用原始有效成分；
- 风化采样点：使用问题一预测得到的风化前成分；
- 同一文物有多个有效采样点时：先按文物编号求平均，形成一件文物一条成分记录。

这样得到的样本更接近文物原始玻璃配方，适合用于类别规律和亚类划分。

同时保留一套原始有效数据作为对照，用于敏感性分析。

### 2.3 成分数据变换

化学成分是比例数据，存在总和约束。设第 \(i\) 件文物第 \(j\) 种成分含量为 \(x_{ij}\)，先进行闭合归一化：

\[
z_{ij}=100\frac{x_{ij}}{\sum_{k=1}^{p}x_{ik}}.
\]

为处理 0 值并削弱闭合效应，加入伪计数 \(\varepsilon\)，再做 CLR 变换：

\[
y_{ij}
=\ln(z_{ij}+\varepsilon)
-\frac{1}{p}\sum_{k=1}^{p}\ln(z_{ik}+\varepsilon).
\]

后续判别模型和聚类模型均以 CLR 变换后的成分为主要输入；描述性结果仍使用原始百分比或闭合后的百分比解释。

## 3. 高钾玻璃与铅钡玻璃的分类规律

### 3.1 主要判别成分

两类玻璃的助熔剂来源不同，成分特征具有明确差异：

- 高钾玻璃以含钾物质为助熔剂，表现为 \(K_2O\) 较高，\(PbO\)、\(BaO\) 接近 0；
- 铅钡玻璃以铅矿石等为助熔剂，表现为 \(PbO\)、\(BaO\) 较高，\(K_2O\) 很低；
- \(SiO_2\) 是玻璃基体成分，铅钡玻璃中因 \(PbO\)、\(BaO\) 占比较高，\(SiO_2\) 相对较低。

因此，大类分类的核心成分选为：

\[
SiO_2,\ K_2O,\ PbO,\ BaO,\ CaO,\ Al_2O_3.
\]

其中 \(PbO+BaO\) 和 \(K_2O\) 是最直接的类别判别指标。

### 3.2 可解释判别指标

构造铅钡特征相对高钾特征的对数比指标：

\[
R_i=\ln\frac{PbO_i+BaO_i+\varepsilon}{K_2O_i+\varepsilon}.
\]

当 \(R_i\) 较大时，说明铅钡特征强，样本更可能为铅钡玻璃；当 \(R_i\) 较小时，说明高钾特征强，样本更可能为高钾玻璃。

阈值 \(R_0\) 不主观指定，而是在已知类别样本中通过最大化分类准确率或 Youden 指数确定：

\[
R_i\geq R_0 \Rightarrow \text{铅钡玻璃},
\qquad
R_i<R_0 \Rightarrow \text{高钾玻璃}.
\]

该规则具有清晰的化学解释，可作为论文中的主要分类规律。

### 3.3 统计判别模型

为验证上述规则，可建立 Logistic 判别模型：

\[
\operatorname{logit}(P_i)
=\beta_0+\beta_1\,clr(PbO_i+BaO_i)
+\beta_2\,clr(K_2O_i)
+\beta_3\,clr(SiO_{2i})
+\cdots,
\]

其中 \(P_i\) 表示第 \(i\) 件文物属于铅钡玻璃的概率。实际建模时可使用选定成分的 CLR 变量作为输入。

样本量不大时，应避免过多变量。建议采用两种模型并列验证：

1. 简单阈值模型：使用 \(R_i\) 给出直观规则；
2. Logistic 或 Fisher 判别模型：使用少量核心成分验证分类准确性。

模型性能用留一交叉验证评价：

\[
Acc=\frac{\text{正确分类文物数}}{\text{文物总数}}.
\]

若阈值模型和统计模型均能稳定区分高钾与铅钡，则说明大类分类规律可靠。

## 4. 高钾玻璃的亚类划分

### 4.1 高钾玻璃候选成分

高钾玻璃内部亚类划分应围绕钾助熔剂、玻璃基体、稳定剂和杂质成分展开。候选成分为：

\[
SiO_2,\ K_2O,\ CaO,\ MgO,\ Al_2O_3,\ Fe_2O_3,\ CuO.
\]

选择理由如下：

- \(K_2O\)：反映高钾助熔剂特征；
- \(CaO\)、\(MgO\)：反映稳定剂或原料差异；
- \(Al_2O_3\)、\(Fe_2O_3\)：反映矿物杂质和原料来源；
- \(CuO\)：可能反映着色差异；
- \(SiO_2\)：反映玻璃基体比例。

### 4.2 高钾亚类命名思路

聚类完成后，根据各类中心或中位数进行命名。可预期的高钾亚类包括：

| 亚类名称 | 主要特征 | 解释 |
|---|---|---|
| 高硅低钾型 | \(SiO_2\) 高，\(K_2O\) 偏低 | 可能受风化影响或原始配方中助熔剂比例较低 |
| 高钾钙铝型 | \(K_2O\)、\(CaO\)、\(Al_2O_3\) 较高 | 钾助熔剂和稳定剂特征明显 |
| 铜铁富集型 | \(CuO\)、\(Fe_2O_3\) 较高 | 可能与着色或含铁铜矿物杂质有关 |

最终亚类名称应以实际聚类中心为准，而不是预先固定。

## 5. 铅钡玻璃的亚类划分

### 5.1 铅钡玻璃候选成分

铅钡玻璃内部亚类划分应围绕铅钡助熔剂及伴生成分展开。候选成分为：

\[
SiO_2,\ PbO,\ BaO,\ P_2O_5,\ SrO,\ CuO.
\]

选择理由如下：

- \(PbO\)、\(BaO\)：铅钡玻璃最核心的类别成分；
- \(P_2O_5\)：在部分风化或原料差异样本中可能明显富集；
- \(SrO\)：常与钡、铅矿物伴生，能够反映原料差异；
- \(CuO\)：反映着色或铜质杂质；
- \(SiO_2\)：反映玻璃基体比例。

### 5.2 铅钡亚类命名思路

聚类后根据类中心进行命名，可预期的铅钡亚类包括：

| 亚类名称 | 主要特征 | 解释 |
|---|---|---|
| 富铅型 | \(PbO\) 高，\(BaO\) 相对较低 | 铅助熔剂特征更强 |
| 铅钡均衡型 | \(PbO\)、\(BaO\) 均较高 | 典型铅钡玻璃成分结构 |
| 磷锶富集型 | \(P_2O_5\)、\(SrO\) 较高 | 可能反映原料伴生或风化残留特征 |

同样，实际命名应服从聚类中心和成分中位数，而不是强行套用固定名称。

## 6. 具体亚类划分方法

### 6.1 聚类流程

分别对高钾玻璃和铅钡玻璃进行亚类划分，流程如下：

1. 选取该大类对应的候选成分；
2. 对文物成分进行闭合归一化；
3. 加入伪计数并进行 CLR 变换；
4. 对选定 CLR 变量标准化；
5. 使用 Ward 层次聚类得到初步亚类结构；
6. 使用 K-means 在相同亚类数下复核聚类结果；
7. 根据类中心、中位数和代表样本解释亚类含义。

Ward 层次聚类适合展示树状图，K-means 适合给出明确类别中心。二者结果一致性越高，亚类划分越可信。

### 6.2 亚类数选择

亚类数 \(K\) 由统计指标和化学解释共同决定。主要依据包括：

1. 类内平方和拐点法；
2. 平均轮廓系数；
3. Ward 聚类树状图的明显分叉；
4. 各亚类是否能形成清晰的成分解释。

轮廓系数定义为：

\[
s_i=\frac{b_i-a_i}{\max(a_i,b_i)},
\]

其中 \(a_i\) 为样本 \(i\) 到同类样本的平均距离，\(b_i\) 为样本 \(i\) 到最近其他类样本的平均距离。平均轮廓系数越大，聚类结构越清晰。

考虑样本量较小，亚类数不宜过多。高钾玻璃建议优先比较 \(K=2,3\)，铅钡玻璃可比较 \(K=2,3,4\)。若增加亚类数不能带来清晰解释，则选择较小的 \(K\)。

### 6.3 结果输出格式

最终应输出以下结果表：

| 文物编号 | 原大类 | 亚类编号 | 亚类名称 | 主要判别成分 |
|---|---|---|---|---|

并分别给出每个亚类的成分中心：

| 原大类 | 亚类 | 样本数 | \(SiO_2\) | \(K_2O\) | \(PbO\) | \(BaO\) | 主要特征 |
|---|---:|---:|---:|---:|---:|---:|---|

对于论文展示，可配合 PCA 二维散点图。PCA 仅用于可视化，不作为主要建模依据。

## 7. 分类结果的合理性分析

### 7.1 大类分类合理性

大类分类结果从化学机理上应满足：

- 铅钡玻璃样本具有较高 \(PbO+BaO\)；
- 高钾玻璃样本具有较高 \(K_2O\)，且 \(PbO\)、\(BaO\) 接近 0；
- \(SiO_2\) 与 \(PbO+BaO\) 在比例上通常呈反向变化。

如果阈值模型、Logistic 判别模型和已知标签高度一致，则说明大类分类规律合理。

### 7.2 亚类划分合理性

亚类划分合理性从三方面评价：

1. 类内相似性：同一亚类内样本的 CLR 距离较小；
2. 类间差异性：不同亚类在关键成分中心上差异明显；
3. 化学可解释性：每个亚类名称能对应明确的成分特征。

若某个亚类只有极少样本，或只由单个异常成分决定，应在论文中将其标记为边界类或特殊样本，而不能过度解释为稳定亚类。

## 8. 敏感性分析

### 8.1 风化修正敏感性

使用两套数据重复分类和聚类：

1. 风化修正数据；
2. 原始有效数据。

比较大类判别结果和亚类划分是否变化。若大类分类基本不变，说明高钾与铅钡的主要差异足够强；若亚类有部分变化，说明亚类比大类更受风化修正影响。

### 8.2 伪计数敏感性

改变 CLR 伪计数：

\[
\varepsilon \in \{0.05,\ 0.10,\ 0.50\},
\]

重复大类分类和亚类聚类，统计样本类别是否稳定。若微量成分较多，较大的伪计数可能影响接近 0 的成分，因此需报告其影响范围。

### 8.3 特征选择敏感性

对关键成分进行删除检验：

- 大类分类中分别去掉 \(PbO\)、\(BaO\)、\(K_2O\)；
- 高钾亚类中分别去掉 \(K_2O\)、\(CaO\)、\(Al_2O_3\)；
- 铅钡亚类中分别去掉 \(PbO\)、\(BaO\)、\(P_2O_5\)。

若去掉某个成分后聚类结构明显变化，说明该成分是该分类结构的重要驱动因素。

### 8.4 Bootstrap 稳定性

对文物样本进行 Bootstrap 重抽样，重复聚类 \(B\) 次。对第 \(i\) 件文物定义稳定性指标：

\[
S_i=\frac{\text{第 }i\text{ 件文物保持原类别或原亚类的次数}}{B}.
\]

若大多数样本 \(S_i>0.8\) 或 \(S_i>0.9\)，说明分类结果稳定；若个别样本稳定性低，应列为边界样本，在结果解释中单独说明。

## 9. 问题二预期结论写法

问题二正文最后可概括为：

1. 高钾与铅钡玻璃的大类区分主要由 \(PbO+BaO\)、\(K_2O\) 和 \(SiO_2\) 决定。铅钡玻璃表现为高 \(PbO\)、高 \(BaO\)、低 \(K_2O\)；高钾玻璃表现为较高 \(K_2O\)、高 \(SiO_2\)、低 \(PbO\) 和 \(BaO\)。
2. 大类分类可用 \(R=\ln[(PbO+BaO+\varepsilon)/(K_2O+\varepsilon)]\) 给出可解释阈值规则，并通过 Logistic 或判别模型进行交叉验证。
3. 高钾玻璃内部应重点依据 \(SiO_2\)、\(K_2O\)、\(CaO\)、\(Al_2O_3\)、\(MgO\)、\(Fe_2O_3\)、\(CuO\) 划分亚类；铅钡玻璃内部应重点依据 \(SiO_2\)、\(PbO\)、\(BaO\)、\(P_2O_5\)、\(SrO\)、\(CuO\) 划分亚类。
4. 亚类结果需要同时满足统计可分性和化学可解释性。大类分类预期较稳定，亚类划分可能对风化修正、伪计数和变量选择更敏感，需通过敏感性分析标记边界样本。

该方案与问题一衔接紧密：问题一负责修正风化影响，问题二在风化修正后的原始配方近似数据上建立分类和亚类结构，为问题三未知样本鉴别提供分类规则和敏感性评价框架。
