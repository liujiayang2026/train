# 统一符号

| 符号 | 含义 | 单位 |
|---|---|---|
| `t` | 观测时间 | 时间 |
| `H(t)` | 水位 | m |
| `Q(t)` | 流量 | m³/s |
| `C(t)` | 含沙量 | kg/m³ |
| `F_s(t)=Q(t)C(t)` | 沙通量 | kg/s |
| `W_y=∫Qdt` | 年总水量 | m³，表中常用 10⁸m³ |
| `M_y=∫QCdt` | 年总排沙量 | kg，表中常用 10⁴t |
| `x` | 断面距离坐标 | m |
| `z_b(x,t)` | 河底高程 | m |
| `Δz` | 后期减前期河底高程变化；正为淤积、负为冲刷 | m |
| `A_net=∫Δz dx` | 断面净变化；正为净淤积、负为净冲刷 | m² |
| `R_0` | 有界模型初始净淤积率 | m²/年 |
| `τ` | 河床形态调整时间常数 | 年 |
