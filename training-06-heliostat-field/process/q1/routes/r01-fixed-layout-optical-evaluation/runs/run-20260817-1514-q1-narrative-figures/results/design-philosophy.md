# 因果光学

信息应沿因果关系流动，而不是堆积成说明。空间中的每一次推进都对应一次物理状态变化：输入成为方向，方向成为反射，反射经历筛选，筛选最终成为数值。构图以清晰的前后关系建立节奏，让观看者不依赖大段文字也能恢复完整推理。

尺度变化是叙事的核心语言。宏观镜场、邻镜局部、单面镜和单条射线以连续缩放连接，重复出现的中心标记像坐标锚点一样维持方向感。每一个缩放窗口都经过精密校准，边界、引线与留白体现长期打磨的专业判断。

色彩承担稳定且唯一的语义：太阳黄表示输入，光学蓝表示计算主线，绿色表示保留的有效能量，朱红表示溢出，玫红与橙色分别表示阴影和遮挡，紫色只表示二者重叠。颜色不装饰结论，而是让因果在远距离观看时仍然成立。

文字保持克制，只留下动作、数值和判定。等宽小标签记录可复算参数，中文标题负责建立阅读层级；公式像标尺一样嵌入画面，而不是取代画面。所有对齐、字号和线宽都应呈现大师级制图的耐心，像经过无数轮推敲后才留下的必要痕迹。

每张图既独立完成一个判断，又与下一张图自然衔接。远看时能读出问题、方法和结论的顺序，近看时能核对真实坐标、样本分类与效率分母。作品的审美来自严谨的一致性，任何优雅都必须建立在物理正确和数据可追溯之上。
