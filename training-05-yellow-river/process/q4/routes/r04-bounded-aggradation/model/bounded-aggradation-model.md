# 断面净淤积约束下的有界趋稳模型

## 1. 反事实约束

在无调水调沙情景下，不把6—7月河床变化置零，而是假定断面长期净淤积：

\[
\int_{1820}^{2050}\Delta z(x,T)\,\mathrm dx>0.
\]

该约束只作用于整个断面，局部主槽仍允许出现 \(\Delta z(x,T)<0\)。

## 2. 数据驱动的空间形态

由附件2构造四段年化河底变化率 \(r_j(x)\)，对应时段为2016-10-20至2017-05-11、2018-09-13至2019-04-13、2019-10-15至2020-03-19和2020-03-19至2021-03-14。其净断面年变化为

\[
R_j=\int r_j(x)\,\mathrm dx.
\]

先去除每段的断面均值，再取逐点中位数，得到稳健的局部冲淤形态：

\[
s_0(x)=\operatorname{median}_j\left[r_j(x)-\frac{R_j}{L}\right],
\qquad L=2050-1820.
\]

再校正为零积分形态 \(s(x)\)，使 \(\int s(x)\,\mathrm dx=0\)。

## 3. 净淤积率情景

四段数据中净断面年变化为正的观测值形成净淤积样本。将其最小值、中位数和最大值分别作为低、中、高情景的初始净淤积率 \(R_0\)。初始空间速率为

\[
r_0(x)=s(x)+\frac{R_0}{L},
\]

因此严格满足 \(\int r_0(x)\,\mathrm dx=R_0>0\)，但不要求所有 \(r_0(x)>0\)。

## 4. 有界趋稳演化

考虑河床抬高后的形态反馈，令变化速率指数衰减：

\[
r(x,t)=r_0(x)e^{-t/\tau},
\]

则从2023至 \(T\) 年的累计变化为

\[
\Delta z(x,T)=r_0(x)\tau\left(1-e^{-T/\tau}\right).
\]

当 \(T\to\infty\) 时，累计变化趋于有限上界 \(r_0(x)\tau\)，不会产生GM式指数爆炸。中心情景取 \(\tau=10\) 年，另取5年和20年作敏感性检验。

## 5. 解释边界

该模型是带工程机理先验的条件情景预测。净淤积方向来自明确假设，附件数据负责确定数量级和空间分配；因此结果不能被表述为由观测数据独立证明的因果事实。第四段跨过6—7月，可能混有天然汛期和工程调度，其作用通过低—中—高包络而非单值真值体现。
