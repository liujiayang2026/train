# 附件2河床断面探索性可视化摘要

## 数据覆盖

- 共读取9期断面，日期为2016-06-08至2021-03-14。
- 单期有效测点为88—216个；原始最大起点距离为4583—6153 m。
- 全部测次共同覆盖区为0—4583 m，本次仅在该区间按5 m网格线性插值，共917个网格点；没有外推。

## 图上首先可见的结构

1. 各期断面都显示约1700—2100 m附近存在主要深槽，但最低点位置会变化；共同网格上的深槽位置从1735 m到2060 m不等。
2. 共同区平均河底高程由2016-06-08的45.073 m升至2017-09-05的45.331 m，随后降至2019-10-15的44.869 m，2021-03-14回到44.960 m。
3. 相邻测次中，2018-09-13至2019-04-13的共同区平均高程变化最低，为-0.315 m；2019-04-13至2019-10-15继续为-0.134 m。负值只表示后期断面更低，不能仅凭测次间差值归因为调水调沙。
4. 2020-03-19至2021-03-14的共同区平均变化为+0.0247 m，整体变化较小，但局部仍同时存在冲刷与淤积。

## 使用边界

- 这些图展示的是断面几何和相邻测次差异，不是调水调沙效果的最终识别。
- 相邻日期间隔为117—373天，通常同时跨越调度期和非调度期；后续必须接入附件1的区间水沙驱动，并利用附件3更密集的6—7月观测拆分事件前后变化。
- 红色表示后期河底更高，蓝色表示后期河底更低；断面变化积分单位为平方米，只能解释为断面冲淤面积或单位河长体积代理。
