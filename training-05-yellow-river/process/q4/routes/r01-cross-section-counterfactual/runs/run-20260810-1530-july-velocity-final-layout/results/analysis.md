# 6—7月流速增强与河床冲淤响应

## 1. 流速是否增加

增加明显。断面面积加权平均流速从4月基线到7月末分别变化为：

- 2020年：1.780 → 2.335 m/s，增加0.555 m/s，增幅31.2%；
- 2021年：1.392 → 2.663 m/s，增加1.271 m/s，增幅91.3%；
- 2022年：1.526 → 2.302 m/s，增加0.776 m/s，增幅50.9%。

垂线算术平均和断面面积加权平均的方向一致，横向流速分布图也显示7月大部分垂线高于4月基线。因此“调水期间水动力没有增强”与附件3数据不符。

## 2. 7月内部变化

从7月首测到末测，断面面积加权流速分别变化为：

- 2020年：2.164 → 2.335 m/s，增加7.9%；
- 2021年：2.017 → 2.663 m/s，增加32.1%；
- 2022年：2.765 → 2.302 m/s，降低16.7%，但末测仍比4月基线高50.9%。

主槽2005—2040 m每期通常只有1条有效流速垂线，不能称为完整主槽面积平均；点位证据的7月首末变化分别为+9.1%、+32.7%和−11.3%，与断面整体方向一致。

## 3. 为什么流速增加仍会淤积

主槽2005—2040 m的7月平均河床高程变化为：2020年+0.32 m、2021年+0.58 m、2022年−0.86 m。也就是说，2020、2021年流速增强但主槽淤积，2022年则发生强冲刷。

附件1显示2020年7月10—11日平均含沙量约16.7—24.3 kg/m³，7月末仍约17.2 kg/m³；2021年7月8日平均含沙量约45.1 kg/m³，7月22日约14.4 kg/m³。较高流速提高输沙能力，但同步输入的高含沙水体也增加泥沙供给。当来沙量相对输沙能力偏大，断面仍可能落淤；因此流速增加与河床冲刷不是一一对应关系。

2022年缺少附件1水沙过程，但附件3显示7月7日面积加权流速达到2.765 m/s，随后一度降到1.293 m/s，再恢复至约2.30 m/s；同期主槽明显下切。强冲刷可能与早期高流速脉冲及累计水动力有关，不能只用“首末流速差”为负来否定其作用。

## 4. 工程效果判断

该工程在提高断面流速和水动力方面效果明显；但在本观测断面的冲刷减淤效果存在显著年际差异：2020、2021年表现为“增速但淤积”，2022年表现为强冲刷。因此当前应评价为“水动力响应明确，河床减淤目标在该断面并非每年实现”，而不是笼统表述为工程无效或始终有效。

这一结论仅对应附件3观测断面，不能直接外推为整个黄河下游河段的总体工程成效。后续需要把累计水量、累计输沙量和水沙不匹配指标引入模型，解释三年的不同方向。
