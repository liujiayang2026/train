2017年CUMCM B题“拍照赚钱”的任务定价
问题二分析与建模思路

一、问题目标

问题二要求为附件一中的历史任务设计新的定价方案，并与原方案比较。

本问的核心不是简单提高所有任务价格，也不是重新拟合原价格，而是利用问题一得到的任务完成规律，估计每个任务在不同价格下的完成概率，再在平台成本约束下优化各任务价格。

总体路线为：

问题一完成概率模型
→ 估计各任务在不同候选价格下的完成概率
→ 建立成本与完成率优化模型
→ 求解各任务新价格
→ 比较原方案与新方案
→ 进行空间分析和稳健性检验。


二、需要修正的关键认识

1. 平台成本不能只用全部任务标价之和表示

任务未完成时，平台通常不需要支付任务酬金。因此，全部任务标价之和只能表示平台的最大承诺金额，不能完全代表实际支出。

原方案的实际支付金额为：

C_old_actual = Σ P_i Y_i

其中：

P_i为原任务价格；
Y_i为任务实际完成状态。

新方案没有真实实施结果，应使用预计支付金额：

C_new_expected = Σ P_i' p_i(P_i')

其中：

P_i'为新价格；
p_i(P_i')为任务在新价格下的预测完成概率。

为保持比较口径一致，优化中的基准成本最好使用原方案在同一个模型下的预计支付金额：

C_0 = Σ P_i p_i(P_i)

原方案的实际支付金额可以作为辅助统计指标单独报告。


2. 完成概率模型得到的是价格响应估计，不是严格因果效应

历史数据中，每个任务只观察到一个实际标价，无法直接知道同一个任务改成其他价格后是否能够完成。

原价格还与任务位置和会员分布有关。例如：

会员密集地区价格通常较低；
偏远任务价格通常较高；
深圳等区域同时存在低价和高未完成率。

因此，价格系数可能同时包含真实价格激励、区域差异、平台原定价规则和未观测任务难度。

论文中应使用：

“模型估计的价格响应”
“预测完成概率”
“预期实施效果”

不能使用：

“提高价格必然使任务完成”
“新方案实际完成率达到某值”


3. 任务之间并非完全独立

同一会员的时间和任务配额有限，完成一个任务可能影响其他任务。因此，多个任务共享有限会员供给。

主模型可以先使用任务完成概率之和近似预计完成数，但必须说明任务独立假设的局限。若条件允许，可进一步增加区域会员承接能力约束。


三、第一阶段：任务完成概率模型

1. 因变量

定义：

Y_i = 1，任务i完成；
Y_i = 0，任务i未完成。

模型目标是估计：

p_i(P) = Pr(Y_i=1 | P, X_i)

其中P为候选任务价格，X_i为任务i的固定空间和供需特征。


2. 价格变量

P_i表示任务价格，是问题二中可以调整的决策变量。

为了符合经济意义，应对模型施加单调性约束：

β_price ≥ 0

即在其他条件相同的情况下，提高价格不能降低预测完成概率。


3. 最近会员距离

利用Haversine公式计算任务与会员之间的地理距离，定义：

D_i = min_j d_ij

表示任务i到最近会员的距离。


4. 周边会员数量

N_i(r) = Σ_j I(d_ij ≤ r)

分别计算1 km、2 km、3 km和5 km范围内的会员数，并通过交叉验证选择适当邻域半径。


5. 会员预订能力

附件二给出了会员预订任务限额、开始预订时间和信誉值。

不建议一开始就人为确定综合权重。主模型可以分别构造：

Q_i：任务周围会员预订限额之和；
R_i：任务周围会员信誉加权值；
T_i：任务周围可较早开始预订的会员比例。

让模型自动估计这些指标的影响。

如果后续需要构造综合有效供给指标，可以写成：

S_i = Σ_j I(d_ij≤r) w_j exp(-λd_ij)

其中w_j通过主成分分析、熵权法或模型估计确定，不主观指定。


6. 任务密度

G_i(r) = Σ_(k≠i) I(d_ik≤r)

表示任务i周围一定距离内的其他任务数量。

主模型使用任务数量作为固定竞争环境，避免新价格变化后竞争指标同时变化造成求解困难。


7. 区域变量

问题一表明深圳、广州—佛山、东莞等区域存在明显差异，因此加入区域固定效应：

R_ir = 1，任务i属于区域r；
R_ir = 0，任务i不属于区域r。

区域可以通过空间网格、K-means或具有明确地理意义的区域划分得到。


8. Logistic完成概率模型

主模型采用带正则化和价格单调约束的Logistic回归：

p_i(P)
= 1 / {1 + exp[-z_i(P)]}

其中：

z_i(P)
= β_0 + β_1P + β_2D_i + β_3N_i
  + β_4Q_i + β_5R_i + β_6T_i
  + β_7G_i + Σ_r γ_rR_ir

约束：

β_1 ≥ 0

该模型输出每个任务在65～85元候选价格下的预测完成概率。


四、完成概率模型验证

1. 空间分块交叉验证

不能只使用普通随机交叉验证。

因为相邻任务具有相似的会员环境、城市交通条件、任务密度和价格水平，随机划分会使相邻任务同时进入训练集和测试集，导致模型评估结果虚高。

建议步骤：

第一步：将任务划分为若干空间网格或空间聚类区域；
第二步：每次留出一个完整区域作为验证集；
第三步：使用其他区域训练模型；
第四步：汇总所有区域的预测结果。


2. 评价指标

应至少报告：

AUC：评价模型对完成和未完成任务的排序能力；
Brier得分：评价预测概率误差；
Log Loss：评价概率预测质量；
概率校准曲线：检查预测为70%的任务是否大约有70%实际完成；
空间分块验证结果：检查模型能否推广到未见区域。

由于问题二使用预测概率进行优化，概率校准比单纯分类准确率更重要。


3. 单调性检查

选取不同区域和不同供需条件的代表性任务，绘制：

价格P → 预测完成概率p_i(P)

检查价格从65元增加到85元时，预测完成概率是否单调不下降。


五、相似任务价格响应验证

为了减弱原价格与空间环境之间的混杂，可以对任务进行分层或匹配。

按照以下特征寻找相似任务：

所属区域；
周边会员数量；
任务密度；
最近会员距离；
会员预订能力。

在相似任务组内部比较不同价格任务的完成率。

如果相似空间环境下，高价任务完成率仍明显较高，则可以增强价格响应估计的可信度。

该分析仍不能完全证明因果关系，但比直接比较全部任务的价格和完成率更加合理。


六、第二阶段：新定价优化模型

1. 候选价格集合

根据原方案价格范围和定价习惯，设：

P_i' ∈ {65, 65.5, 66, …, 84.5, 85}

价格步长为0.5元。


2. 主优化目标

最大化预计完成任务数：

max Σ_i p_i(P_i')


3. 预计支付成本约束

保守方案要求新方案预计支付金额不超过原方案预计支付金额：

Σ_i P_i' p_i(P_i')
≤ Σ_i P_i p_i(P_i)

该约束能够在相同预测口径下公平比较新旧方案。


4. 价格调整幅度约束

为了避免模型产生大量65元和85元的极端价格，增加：

|P_i' - P_i| ≤ 5

即单个任务相对原价格最多调整5元。


5. 价格范围和离散约束

65 ≤ P_i' ≤ 85

并且P_i'必须以0.5元为步长。


6. 修正后的主模型

max Σ_i p_i(P_i')

满足：

Σ_i P_i' p_i(P_i')
≤ (1+δ) Σ_i P_i p_i(P_i)

P_i' ∈ {65, 65.5, …, 85}

|P_i' - P_i| ≤ 5

其中：

δ=0：保守方案；
δ=0.05：平衡方案；
δ=0.10：完成优先方案。


七、成本—完成率多场景方案

不建议只给一个精确的新方案，而应设计三个场景。

1. 保守方案

δ=0

预计支付金额不增加，在原成本水平下最大化预计完成数。


2. 平衡方案

δ=0.05

允许预计支付金额增加5%，作为推荐实施方案。


3. 完成优先方案

δ=0.10

允许预计支付金额增加10%，用于分析完成率能够改善到什么程度。


通过三个场景绘制成本—预计完成率前沿曲线，并选择曲线边际收益明显下降的拐点作为推荐方案。


八、优化求解方法

1. 边际完成概率

任务价格提高0.5元带来的预测完成概率增量为：

Δp_i(P)
= p_i(P+0.5) - p_i(P)


2. 边际预计成本

预计支付成本为：

c_i(P) = P p_i(P)

从P提高到P+0.5后的预计成本增量为：

Δc_i(P)
= (P+0.5)p_i(P+0.5) - Pp_i(P)


3. 单位预计成本边际收益

M_i(P)
= Δp_i(P) / Δc_i(P)

M_i越大，说明把下一笔价格预算分配给任务i越有效。


4. 边际收益分配算法

第一步：为每个任务确定允许的最低价格：

P_i,min = max(65, P_i-5)

第二步：计算初始方案的预计支付金额。

第三步：对每个尚未达到上限的任务，计算价格增加0.5元的M_i。

第四步：优先给M_i最大的任务提高0.5元。

第五步：更新该任务的完成概率、预计成本和下一次边际收益。

第六步：重复分配，直到达到场景成本上限。


5. 更严格的求解方法

由于每个任务有有限个候选价格，可以将问题写成多选择背包模型。

定义二元变量：

x_ik = 1，任务i选择候选价格k；
x_ik = 0，任务i不选择候选价格k。

每个任务只能选择一个价格：

Σ_k x_ik = 1

目标：

max Σ_i Σ_k p_ik x_ik

成本约束：

Σ_i Σ_k P_ik p_ik x_ik ≤ C_max

如果有可用的整数规划求解器，可以将多选择背包模型作为最终求解方法；边际收益算法可作为易于解释的近似算法。


九、任务竞争的处理

主模型使用固定的周边任务数量G_i，不直接使用依赖新价格的竞争强度。

原因是相对价格竞争指标：

C_i
= Σ_(k≠i) I(d_ik≤r) exp[η(P_k-P_i)]

会随着所有任务新价格同时改变。如果在优化时固定历史竞争强度，会产生逻辑不一致。

可将价格竞争作为扩展模型，采用迭代方法：

第一步：用原价格计算竞争强度；
第二步：求解一次新价格；
第三步：使用新价格更新竞争强度；
第四步：重新估计完成概率并优化价格；
第五步：直到相邻两轮价格变化不超过0.5元。

第二问主模型可以不使用这一复杂迭代，把任务相对价格竞争留到第三问打包分析中进一步处理。


十、区域会员承接能力

由于任务共享有限会员资源，可考虑增加区域容量约束：

Σ_(i∈A_r) p_i(P_i') ≤ K_r

其中K_r表示区域r能够承接的预计任务数量。

可根据区域内会员预订限额和历史完成数估计：

K_r = κ Σ_(j∈A_r) q_j*

其中q_j*为标准化后的会员预订能力，κ通过历史区域完成任务数校准。

由于附件没有会员实际完成任务的对应记录，这一约束可能存在较大估计误差。因此建议：

主模型不强制加入容量约束；
将区域容量作为扩展模型或局限性分析；
检查优化后某一区域的预计完成任务数是否明显超过历史承接能力。


十一、新价格的预期空间结构

1. 深圳失败热点

深圳区域原平均价格较低、未完成率较高。新方案应提高其中价格响应明显、局部竞争较强的低价任务。

不能对深圳所有任务统一加价，只应对单位预计成本边际收益较高的任务加价。


2. 广州—佛山任务密集区

该区域相邻任务多，原低价任务和未完成任务混合分布。

新方案应：

提高竞争中处于劣势且价格响应较高的任务；
降低完成概率已经较高、加价边际收益很低的任务；
避免相邻任务长期维持大量相同低价。


3. 东莞高完成区域

东莞附近原完成率较高。部分容易完成任务可以适当降低价格，将预计成本空间转移到深圳和广州失败热点。

降价仍需满足单任务最大调整幅度，避免破坏原有高完成状态。


4. 偏远任务

外围和偏远任务不能统一降价。问题一表明部分偏远任务能够完成，很可能正是由于原方案已经给予距离补偿。

只有模型预测在降价后仍能保持较高完成概率时，才能减少价格。


十二、新旧方案比较指标

1. 全部任务标价总额

B = Σ_i P_i

该指标表示最大承诺金额。


2. 预计支付金额

C = Σ_i P_i p_i(P_i)

这是成本比较的主要指标。


3. 原方案实际支付金额

C_actual = Σ_i P_iY_i

该指标作为历史事实单独报告。


4. 预计完成任务数

E(N) = Σ_i p_i(P_i)


5. 预计完成率

R_hat = (1/835)Σ_i p_i(P_i)


6. 单位预计完成成本

CE = Σ_i P_i p_i(P_i) / Σ_i p_i(P_i)

该指标表示预计每完成一个任务所需的平均支付金额。


7. 价格调整统计

报告：

提价任务数量；
降价任务数量；
价格不变任务数量；
平均调整幅度；
最大提价幅度；
最大降价幅度；
各价格区间任务数量变化。


8. 区域比较

分别计算深圳、广州—佛山、东莞和外围区域的：

原平均价格；
新平均价格；
原预测完成率；
新预测完成率；
预计支付金额变化；
未完成热点改善程度。

十四、灵敏度分析

1. 邻域半径

分别测试1 km、2 km、3 km和5 km。


2. 价格调整幅度

比较最大调整幅度为3元、5元和8元时的结果。


3. 价格上限

比较价格上限为80元、85元和90元时的完成率改善。


4. 成本预算

比较预计支付金额变化为：

0%；
+5%；
+10%。


5. 价格响应强度

将估计的价格系数分别调整为基准值的：

80%；
100%；
120%。

观察新方案是否对价格响应估计过于敏感。


十五、模型局限性

1. 历史数据不能直接识别同一个任务在其他价格下的真实完成情况；

2. 价格与区域、会员密度和任务难度存在混杂关系；

3. 缺少会员实际领取任务和完成任务的对应记录；

4. 缺少交通时间、停车成本和任务发布时间等变量；

5. 完成概率之和近似忽略了任务之间共享会员容量；

6. 新方案的完成率属于模型预测结果，不是实际实施结果；

7. 区域固定效应只能吸收综合差异，不能直接证明某一类具体城市成本。


十六、推荐的最终方案

建议将“平衡方案”作为推荐方案：

允许预计支付金额比原方案增加不超过5%，在价格范围65～85元、单任务调整不超过5元的条件下，最大化预计完成任务数。

推荐模型为：

max Σ_i p_i(P_i')

满足：

Σ_i P_i' p_i(P_i')
≤ 1.05 Σ_i P_i p_i(P_i)

P_i' ∈ {65, 65.5, …, 85}

|P_i' - P_i| ≤ 5

同时给出预计支付金额不增加的保守方案和增加10%的完成优先方案，形成完整成本—完成率前沿。


十七、论文建议结构

5 问题二：任务重新定价模型

5.1 问题分析

说明问题二是有限预计支付成本下的任务完成概率优化问题。


5.2 完成概率模型

定义价格、会员供给、任务密度和区域变量，建立单调Logistic模型。


5.3 模型验证

给出空间分块交叉验证、AUC、Brier得分、Log Loss和校准结果。


5.4 新定价优化模型

给出目标函数、预计支付成本约束、价格范围和调整幅度约束。


5.5 模型求解

介绍多选择背包模型或单位预计成本边际收益分配算法。


5.6 新定价结果

报告每个任务的新价格及区域调整规律。


5.7 新旧方案比较

比较预计支付金额、完成率、单位完成成本、价格调整数量和区域改善效果。


5.8 灵敏度分析

分析预算、邻域半径、价格上限和价格响应参数变化。


5.9 问题二结论

说明新方案如何将预计成本从低边际收益任务转移到失败热点，并报告推荐方案的预期实施效果。
