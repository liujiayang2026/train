# 2020—2022年7月河床变化位置与插值方法判断

## 结论

附件3的观测范围主要位于起点距离约1675—2075 m。三年7月首末测次之间的变化并不集中在一个固定坐标，也不保持同一冲淤方向；但约2010—2040 m在三年中反复进入高变化区，是当前最稳定的空间关注区。其次可关注1830—1875 m。边界附近的1680—1685 m和2070—2075 m虽然也满足复现规则，但容易受共同覆盖边界和岸坡陡变影响，解释权重应低于内部区间。

逐年方法一致热点为：

- 2020年（7月10日—29日）：1680—1690、1765—1800、1840—1845、2010—2035 m以淤积为主，2055—2075 m以冲刷为主；PCHIP净断面变化为+36.72 m²。
- 2021年（7月7日—22日）：1825—1880、2020—2035、2070—2075 m以淤积为主；PCHIP净断面变化为+115.11 m²。
- 2022年（7月7日—23日）：1675、1895—1905、1925—1960、2005—2040 m以冲刷为主；PCHIP净断面变化为−182.75 m²。

因此不能把天然深槽1700—2100 m本身当作调水调沙效果，也不能声称存在一个固定的“调水调沙冲刷坐标”。目前最可靠的表述是：2010—2040 m是跨年反复出现的高响应区，但响应方向随年份改变。

## 附件1的事件对齐限制

附件1显示，2020年6月底至7月上旬存在约4000—4970 m³/s的高流量过程，7月10—15日及26—31日存在明显高含沙过程；附件3的7月10日与29日断面夹住了其中大部分高含沙过程。2021年6月底至7月初存在约4000—4240 m³/s的高流量过程，7月7—10日和22—23日存在高含沙过程；附件3的7月7日与22日断面覆盖了这两个过程的主要部分。

附件1仅到2021年，不能校验2022年7月是否对应同口径调水调沙过程。并且附件没有官方“调度开始/结束”标记，所以本run仍以“7月首末测次净变化”作为可复核对象，不把全部差异作严格因果归因。

## 拟合方法选择

附件3全部19期连续3点空间区块留出验证中，PCHIP的RMSE为0.382 m，低于分段线性的0.555 m；7月子集中，PCHIP为0.390 m，低于线性的0.569 m。相对线性，PCHIP的7月RMSE降低约31.5%。两种方法计算的年度净断面变化和主要热点总体一致，说明热点判断不是只由某一种插值器制造。

据此，后续在附件3的1675—2075 m局部断面，尤其2010—2040 m高变化区，采用PCHIP作为主拟合；分段线性继续作为敏感性基准。对共同覆盖区边缘不作外推，也不把5 m计算网格误称为5 m实测分辨率。
