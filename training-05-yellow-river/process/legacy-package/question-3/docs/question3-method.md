# 问题三完整思路与解题过程

> 历史方案说明：本文档记录上一版 STL/季节模板组合模型。当前变点感知的月-日两尺度混合模型见 `question3-analysis.md`。

## 1. 问题理解

问题三需要完成两个任务：

1. 预测未来两年水沙通量变化趋势；
2. 制定未来两年采样监测方案，使监测能覆盖关键变化过程，同时减少不必要的采样成本。

因此本题不是单纯做时间序列预测，而是要把预测结果进一步转化为采样决策。整体流程为：

```text
问题二日尺度水沙通量序列
→ 构建两个可解释基模型
→ 留一年交叉验证确定组合权重
→ 预测 2022-2023 年三情景水沙通量
→ 构造每日采样风险分数
→ 形成枯水期低频、汛期高频、高风险加密的采样方案
```

## 2. 数据基础与预测对象

使用问题二得到的日尺度序列：

```text
project5/question-2/data/processed/daily_flux_series.csv
```

预测对象为两个日尺度变量：

```text
Q_t：第 t 天平均流量，单位 m^3/s
F_t：第 t 天平均沙通量，单位 kg/s
```

其中沙通量已在问题二中计算为：

```text
F_t = Q_t C_t
```

未来预测区间为：

```text
2022-01-01 至 2023-12-31
```

日尺度预测完成后，年径流量和年输沙量分别由逐日累加得到：

```text
W = Σ Q_t × 86400
S = Σ F_t × 86400
```

其中 `W` 的单位为 `m^3`，再换算为 `亿 m^3`；`S` 的单位为 `kg`，再换算为 `万吨`。

## 3. 模型选择思路

前面尝试过三类模型：

| 模型 | 优点 | 问题 |
| --- | --- | --- |
| 递推 Ridge 模型 | 能引入趋势、周期和滞后项 | 长期递推误差传播明显 |
| 随机森林模型 | 属于成熟机器学习模型 | 短样本外推不稳，验证误差较大 |
| STL/季节模板模型 | 符合水沙年周期规律，可解释性强 | 单独使用时各有局限 |

最终采用：

```text
STL-季节模板交叉验证加权组合模型
```

该模型不是简单选一个模型，而是把近期加权季节模板模型和 STL 趋势残差模型进行组合。组合权重由留一年交叉验证确定，避免主观指定。

## 4. 基模型一：近期加权季节模板模型

黄河水沙通量具有显著季节性，6-10 月为主要水沙输移期，7-9 月为高风险输沙期。因此第一个基模型直接利用历史同季节邻域数据。

设预测目标日期为 `τ`，历史日期为 `t`。定义年内日序距离：

```text
D(t, τ) = min(|d_t - d_τ|, 366 - |d_t - d_τ|)
```

选取目标日期前后 15 天的历史同季节样本：

```text
D(t, τ) ≤ 15
```

日期距离权重为：

```text
w_d(t, τ) = exp[-0.5 × (D(t, τ) / 7.5)^2]
```

年份近因权重为：

```text
w_y(t) = exp[-0.42 × (Y_max - Y_t)]
```

其中 `Y_max` 为训练集中最新年份，`Y_t` 为历史样本所在年份。由于 2016-2017 年水沙过程明显低于后期，对 2016-2017 年样本额外乘以 `0.45` 降权。

综合权重为：

```text
w(t, τ) = w_d(t, τ) × w_y(t)
```

平水情景预测取加权平均：

```text
y_template(τ) = Σ w(t,τ)y_t / Σ w(t,τ)
```

偏枯情景取加权低分位数，偏丰情景取加权高分位数。

## 5. 基模型二：STL 趋势残差模型

第二个基模型采用 STL 分解思想。为了削弱洪峰极端值影响，先作对数变换：

```text
Y_t = ln(1 + x_t)
```

其中 `x_t` 可以是 `Q_t` 或 `F_t`。

将序列写成：

```text
Y_t = T_t + E_t
```

其中 `T_t` 为趋势项，`E_t` 为扣除趋势后的季节残差。

趋势项使用近四年年均对数通量拟合：

```text
T_t = a + bt
```

为避免短样本造成趋势过度外推，对斜率进行截断：

```text
水通量趋势斜率限制在 [-0.05, 0.05]
沙通量趋势斜率限制在 [-0.08, 0.08]
```

历史残差为：

```text
E_t = Y_t - T_t
```

预测未来日期 `τ` 时，先外推趋势项，再用历史同季节邻域残差估计季节残差：

```text
Y_stl(τ) = T_hat(τ) + E_hat(τ)
```

最后反变换回原尺度：

```text
x_stl(τ) = exp(Y_stl(τ)) - 1
```

## 6. 交叉验证加权组合

最终预测不是直接采用单个基模型，而是组合：

```text
y_hat(τ) = w y_template(τ) + (1 - w)y_stl(τ)
```

其中 `w` 为季节模板模型权重，`1-w` 为 STL 趋势残差模型权重。

权重通过留一年交叉验证确定。依次使用：

```text
2016-2017 年预测 2018 年
2016-2018 年预测 2019 年
2016-2019 年预测 2020 年
2016-2020 年预测 2021 年
```

对每个候选权重：

```text
w = 0, 0.05, 0.10, ..., 1.00
```

计算四个验证年份的平均 `RMSE_log`，选择误差最小的权重。

水量和沙通量分开确定权重，最终结果为：

| 预测对象 | 季节模板权重 | STL 权重 |
| --- | ---: | ---: |
| 水通量 `Q_t` | 1.00 | 0.00 |
| 沙通量 `F_t` | 0.75 | 0.25 |

这说明水通量主要由近期季节模板解释已经较好；沙通量则需要加入一部分 STL 趋势残差模型进行修正。

## 7. 三情景预测

为反映未来来水来沙条件的不确定性，设置三种情景：

| 情景 | 构造方式 | 含义 |
| --- | --- | --- |
| 偏枯情景 | 历史同季节低分位数 + 较弱趋势外推 | 水沙偏低 |
| 平水情景 | 交叉验证加权组合预测 | 正常年份 |
| 偏丰情景 | 历史同季节高分位数 + 较强趋势外推 | 水沙偏高 |

为了避免偏丰情景因短样本外推而过大，加入同月份历史分位数约束，使预测值保持在历史同季节可解释范围附近。

## 8. 模型验证结果

留一年验证平均结果为：

| 预测对象 | 模型 | RMSE_log | MAE_log |
| --- | --- | ---: | ---: |
| 水通量 | 组合模型 | 0.6301 | 0.4857 |
| 水通量 | 原 STL 模型 | 0.6448 | 0.4953 |
| 沙通量 | 组合模型 | 1.4132 | 1.0951 |
| 沙通量 | 原 STL 模型 | 1.4737 | 1.1492 |

因此优化组合模型比单独 STL 模型误差更低，尤其对沙通量预测改善更明显。

## 10. 采样风险分数

采样方案以平水情景为基础，同时参考偏丰情景风险。对每一天构造风险分数：

```text
R_t =
0.35 × 平水情景沙通量强度
+ 0.10 × 偏丰情景沙通量强度
+ 0.25 × 沙通量变化率
+ 0.15 × 峰值期指标
+ 0.10 × 汛期指标
+ 0.05 × 历史突变月份风险
```

其中连续变量均归一化到 `[0,1]`。

沙通量变化率定义为：

```text
Δ_t = |ln(1 + F_hat_t) - ln(1 + F_hat_{t-1})|
```

峰值期指标对应 7-9 月，汛期指标对应 6-10 月，历史突变月份风险来自问题二的突变事件统计。

## 11. 采样方案

基础采样频率为：

| 时段 | 采样策略 |
| --- | --- |
| 1-3 月 | 约每 10 天一次 |
| 4-5 月 | 约每 5 天一次 |
| 6-10 月 | 约每 2 天一次 |
| 11-12 月 | 约每 7 天一次 |

在此基础上，每年选取风险分数最高的日期及其相邻日期进行加密。

最终建议每年采样约 120 次，重点集中在 7-9 月：

| 月份 | 特征 | 采样安排 |
| --- | --- | --- |
| 1-3 月 | 枯水期，水沙变化较弱 | 低频监测 |
| 4-5 月 | 入汛前，通量开始上升 | 中频监测 |
| 6-10 月 | 汛期，水沙输移集中 | 高频监测 |
| 7-9 月 | 沙通量高、变化快 | 高风险加密 |
| 11-12 月 | 退水期 | 中低频监测 |

## 12. 最终采用理由

最终采用该优化组合模型，理由如下：

1. 相比随机森林，组合模型更适合短时间序列外推，结果更稳定；
2. 相比单独 STL 模型，组合模型的留一年验证误差更低；
3. 权重由交叉验证确定，不是主观指定；
4. 模型同时保留季节规律和趋势解释，便于论文表述；
5. 预测结果能自然转化为采样风险分数和监测方案。
