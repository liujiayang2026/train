# 附件2连续河床断面重建与方法比较

## 1. 目标与范围

对附件2每个实测日期分别重建一维连续断面

\[
z_t(x)=f_t(x),
\]

其中 \(x\) 为距固定岸边起点的距离，\(z_t\) 为1985国家高程基准下的河底高程。本模块只比较空间重建方法，不进行时间外推，也不把天然深槽本身解释为调水调沙效果。

统一计算网格取全部9期严格共同覆盖区0—4583 m，步长5 m。5 m只是积分和绘图网格，不代表5 m实测分辨率；所有方法禁止超出原始覆盖范围外推。

## 2. 候选方法

1. `linear`：相邻实测点分段线性连接，作为最保守审计基准。
2. `pchip`：分段三次Hermite保形插值，保持局部单调性并减少普通三次样条过冲。
3. `penalized_bspline`：显式P-spline。用三次B样条基函数 \(B_j(x)\) 表示 \(f(x)=\sum_j\beta_jB_j(x)\)，最小化

   \[
   \lVert z-B\beta\rVert^2+\lambda\lVert D_2\beta\rVert^2,
   \]

   其中 \(D_2\) 是B样条系数的二阶差分矩阵。每个外层空间留出折都只在其训练子集内用内层区块验证从预设网格选择 \(\lambda\)，避免把外层验证点用于调参；完整断面也单独用区块验证选择 \(\lambda\)。
4. `gcv_smoothing_spline`：三次全局平滑样条，最小化

   \[
   \sum_i[z_i-f(x_i)]^2+\lambda\int[f''(x)]^2\,dx,
   \]

   由广义交叉验证自动选择 \(\lambda\)。
5. `matern_gp`：Matérn-3/2核高斯过程加白噪声项，输出均值和条件标准差；横向距离先缩放至0—1。

`penalized_bspline` 与 `gcv_smoothing_spline` 不等价：二者都可用B样条表示，但前者显式惩罚相邻B样条系数的二阶差分并采用嵌套区块验证选参，后者惩罚连续曲线二阶导并由全局GCV自动选参。当前P-spline尚未加入分段单调或深槽位置硬约束，不能称为“分区约束P-spline”。

水利河床重建文献中常见IDW、RBF、克里金、Topo to Raster、河道坐标变换和流速各向异性距离。本题附件2只有单条固定横断面的一维起点距离，没有平面坐标、中心线、岸线或二维流速场，因此不冒充二维河床DEM重建；本次使用与现有信息维度匹配的一维候选方法。参考：`10.3390/ijgi8110507`、`10.3390/w10091266`、`10.1590/1413-70542017414008617`、`10.1016/j.jhydrol.2016.09.022`。

## 3. 空间区块验证

训练点上的残差不能评价精确插值法。每期保留首末端点作为边界，将内部测点按距离顺序组成连续3点小块，再把小块轮换分配到5折。每折完整移除若干连续空间块，用剩余点重建被遮挡位置。报告逐点和逐日期的RMSE、MAE、偏差、最大绝对误差。

连续3点区块模拟局部漏测，比随机逐点留出更能暴露跨缺口重建能力；但它仍不能验证大于现有测点间距很多的未测区域。

## 4. 形态与稳定性诊断

对完整数据的5 m拟合结果记录：最低河底高程、深泓位置、断面高程积分、曲线粗糙度、最大坡度，以及是否超过该期实测高程范围。再计算各方法相对线性基准的断面积差。模型选择同时考虑区块误差、深槽保持、非物理过冲和断面积稳定性，不因曲线更平滑而自动采用。
