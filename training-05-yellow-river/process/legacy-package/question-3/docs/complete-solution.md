# 问题三完整解题文件

> 历史方案说明：本文档记录上一版 STL/季节模板组合模型。当前主模型、验证指标和 2022-2023 预测结果以 `question3-analysis.md` 及 `code/regime_aware_question3.py` 为准。

## 1. 问题分析

问题三要求预测未来两年的水沙通量变化趋势，并制定未来两年的采样监测方案。该问题可以拆成两个子问题：

1. 根据 2016-2021 年历史水沙过程，预测 2022-2023 年每日水通量和沙通量；
2. 根据预测得到的未来水沙变化过程，设计分季节、分风险等级的采样计划。

因此，本题的关键不是只预测年度总量，而是要获得未来两年的日尺度变化过程。只有得到逐日预测值，才能进一步判断哪些月份、哪些日期水沙通量高、变化快，从而确定采样加密时段。

## 2. 数据来源与变量定义

本题使用问题二得到的日尺度水沙通量数据：

```text
project5/question-2/data/processed/daily_flux_series.csv
```

其中：

| 变量 | 含义 | 单位 |
| --- | --- | --- |
| `Q_t` | 第 `t` 天日均流量 | `m^3/s` |
| `C_t` | 第 `t` 天含沙量 | `kg/m^3` |
| `F_t` | 第 `t` 天日均沙通量 | `kg/s` |

沙通量定义为单位时间通过断面的泥沙质量：

```text
F_t = Q_t C_t
```

其中 `Q_t` 已经是整个断面的流量，表示单位时间通过断面的水体体积，因此计算沙通量时不再额外乘断面面积。

本题预测区间为：

```text
2022-01-01 至 2023-12-31
```

最终需要输出：

1. 逐日预测水通量 `Q_t`；
2. 逐日预测沙通量 `F_t`；
3. 月度、年度水量和输沙量；
4. 未来两年采样计划。

## 3. 建模难点

历史数据呈现出以下特征：

1. 水沙过程具有显著年周期，6-10 月为汛期，7-9 月高沙通量特征突出；
2. 沙通量比流量波动更剧烈，少数汛期高值日对全年输沙量影响很大；
3. 可用历史年份较少，只有 2016-2021 年，复杂机器学习模型容易过拟合；
4. 2022-2023 年预测属于时间外推，模型必须避免外推失控；
5. 采样方案需要基于未来日尺度变化，而不是只基于年度总量。

因此，最终模型应同时满足：

```text
能刻画季节性
能反映近年趋势
验证误差较低
外推结果稳定
便于解释和转化为采样方案
```

## 4. 模型比较与最终选择

建模过程中比较了三类模型。

第一类是递推 Ridge 回归模型。该模型以趋势项、周期项、汛期指标和滞后项作为特征，逐日递推预测未来水沙通量。其优点是形式简单，能引入多类特征；缺点是长期递推时预测误差会累积，尤其对汛期突增过程刻画不够稳定。

第二类是随机森林回归模型。随机森林是成熟的机器学习回归模型，能够拟合非线性关系。但本题只有 6 年历史数据，样本年份较短，随机森林不擅长时间趋势外推，递归预测时滞后项又会放大误差。实际验证结果也表明随机森林误差明显偏大，因此只作为对比模型，不作为主模型。

第三类是 STL 分解与近期加权季节模板模型。该类模型直接利用水沙过程的年周期特征，同时引入近年趋势，对短时间序列更加稳健。单独 STL 模型解释性较强，单独近期加权季节模板模型验证误差较低。为了兼顾两者，最终采用二者的交叉验证加权组合：

```text
STL-季节模板交叉验证加权组合模型
```

最终采用该模型的原因如下：

1. 近期加权季节模板能较好刻画黄河水沙的年周期规律；
2. STL 趋势残差模型能补充趋势解释；
3. 组合权重由留一年交叉验证确定，不是主观设定；
4. 该模型比单独 STL 模型验证误差更低；
5. 相比随机森林，预测结果更稳定，更适合短样本外推。

## 5. 基模型一：近期加权季节模板模型

水沙通量存在明显季节性，因此预测某一未来日期时，应优先参考历史同季节附近的观测值。

设预测日期为 `τ`，其年内日序为 `d_τ`；历史日期 `t` 的年内日序为 `d_t`。定义循环年内距离：

```text
D(t,τ) = min(|d_t - d_τ|, 366 - |d_t - d_τ|)
```

选取与目标日期相差不超过 15 天的历史样本：

```text
D(t,τ) ≤ 15
```

为了使距离目标日期越近的样本权重越大，设置日期距离权重：

```text
w_d(t,τ) = exp[-0.5 × (D(t,τ)/7.5)^2]
```

同时考虑近年数据对未来更有代表性，设置年份近因权重：

```text
w_y(t) = exp[-0.42 × (Y_max - Y_t)]
```

其中 `Y_max` 是训练集中最新年份，`Y_t` 是历史样本所在年份。由于 2016-2017 年水沙通量整体低于 2018 年以后，对 2016-2017 年样本额外降权：

```text
若 Y_t < 2018，则 w_y(t) 再乘 0.45
```

综合权重为：

```text
w(t,τ) = w_d(t,τ) × w_y(t)
```

平水情景下，近期加权季节模板预测为：

```text
y_template(τ) = Σ w(t,τ)y_t / Σ w(t,τ)
```

偏枯情景取历史同季节邻域的加权低分位数，偏丰情景取加权高分位数。

## 6. 基模型二：STL 趋势残差模型

为了分离长期趋势和季节波动，对流量和沙通量分别建立 STL 趋势残差模型。由于水沙通量在汛期存在峰值，为削弱极端值对模型的影响，先进行对数变换：

```text
Y_t = ln(1 + x_t)
```

其中 `x_t` 表示 `Q_t` 或 `F_t`。

将对数序列表示为：

```text
Y_t = T_t + E_t
```

其中：

- `T_t` 为趋势项；
- `E_t` 为扣除趋势后的季节残差项。

趋势项由近四年年均对数通量拟合：

```text
T_t = a + bt
```

由于历史年份较少，趋势外推不能过强，因此对斜率 `b` 进行截断：

```text
水通量趋势斜率限制在 [-0.05, 0.05]
沙通量趋势斜率限制在 [-0.08, 0.08]
```

历史残差计算为：

```text
E_t = Y_t - T_t
```

预测未来日期 `τ` 时，先得到趋势外推值 `T_hat(τ)`，再用历史同季节邻域残差加权得到季节残差 `E_hat(τ)`：

```text
Y_stl(τ) = T_hat(τ) + E_hat(τ)
```

最后反变换回原尺度：

```text
x_stl(τ) = exp(Y_stl(τ)) - 1
```

这样得到 STL 基模型对未来每日流量和沙通量的预测值。

## 7. 组合预测模型

为了同时利用近期加权季节模板的低误差优势和 STL 模型的趋势解释能力，构建线性组合预测模型：

```text
y_hat(τ) = w y_template(τ) + (1 - w)y_stl(τ)
```

其中：

- `y_template(τ)` 是近期加权季节模板预测值；
- `y_stl(τ)` 是 STL 趋势残差模型预测值；
- `w` 是季节模板权重；
- `1-w` 是 STL 模型权重。

水通量和沙通量分别确定权重：

```text
Q_hat(τ) = w_Q Q_template(τ) + (1 - w_Q)Q_stl(τ)
F_hat(τ) = w_F F_template(τ) + (1 - w_F)F_stl(τ)
```

这样做的原因是水通量和沙通量波动机制不同。水通量相对平滑，季节模板已经能较好刻画；沙通量受汛期和高含沙过程影响更强，需要保留一部分趋势残差修正。

## 8. 权重确定方法

组合权重通过留一年交叉验证确定。验证过程如下：

```text
用 2016-2017 年训练，预测 2018 年；
用 2016-2018 年训练，预测 2019 年；
用 2016-2019 年训练，预测 2020 年；
用 2016-2020 年训练，预测 2021 年。
```

候选权重设置为：

```text
w = 0, 0.05, 0.10, ..., 1.00
```

对每个候选权重，计算四个验证年份上的平均对数均方根误差：

```text
RMSE_log = sqrt[mean((ln(1+y_t) - ln(1+y_hat_t))^2)]
```

选择 `RMSE_log` 最小的权重作为最终组合权重。

最终得到：

| 预测对象 | 季节模板权重 | STL 权重 | 平均 RMSE_log |
| --- | ---: | ---: | ---: |
| 水通量 `Q_t` | 1.00 | 0.00 | 0.6301 |
| 沙通量 `F_t` | 0.75 | 0.25 | 1.4132 |

由此可见，水通量预测完全采用近期加权季节模板最优；沙通量预测采用 `75%` 近期加权季节模板和 `25%` STL 趋势残差模型最优。

## 9. 预测计算过程

预测过程按日进行，具体步骤如下。

第一步，确定预测日期序列：

```text
2022-01-01, 2022-01-02, ..., 2023-12-31
```

第二步，对于每一个预测日期 `τ`，分别计算近期加权季节模板预测值：

```text
Q_template(τ), F_template(τ)
```

第三步，对于同一个预测日期 `τ`，计算 STL 趋势残差模型预测值：

```text
Q_stl(τ), F_stl(τ)
```

第四步，代入交叉验证确定的权重，得到平水情景逐日预测：

```text
Q_hat(τ) = 1.00 Q_template(τ) + 0.00 Q_stl(τ)
F_hat(τ) = 0.75 F_template(τ) + 0.25 F_stl(τ)
```

第五步，为了反映未来水沙条件不确定性，分别计算偏枯、平水和偏丰三种情景：

| 情景 | 计算含义 |
| --- | --- |
| 偏枯 | 使用历史同季节低分位数，并降低趋势外推强度 |
| 平水 | 使用交叉验证加权组合的基准预测 |
| 偏丰 | 使用历史同季节高分位数，并增强趋势外推强度 |

第六步，对偏丰情景加入同月份历史分位数约束。其目的是避免短样本外推导致预测值过大。约束思想为：

```text
偏丰预测值不应无限超过历史同月份高分位水平
```

在代码中，对未来每个月份分别参考历史同月份 `95%` 分位数，并结合平水预测值设置上限，使偏丰情景既能体现高水沙风险，又保持在历史经验可解释范围内。

第七步，将逐日流量和沙通量换算为逐日水量和输沙量：

```text
日水量 = Q_hat(τ) × 86400
日输沙量 = F_hat(τ) × 86400
```

第八步，对逐日结果按月、按年汇总：

```text
月水量 = Σ 当月日水量
月输沙量 = Σ 当月日输沙量
年水量 = Σ 全年日水量
年输沙量 = Σ 全年日输沙量
```

最后将单位换算为：

```text
水量：亿 m^3
输沙量：万吨
```

## 10. 模型验证结果

留一年交叉验证的平均结果如下：

| 预测对象 | 模型 | RMSE_log | MAE_log | 原尺度 RMSE | 原尺度 MAE |
| --- | --- | ---: | ---: | ---: | ---: |
| 水通量 | 季节模板 | 0.6301 | 0.4857 | 921.06 | 593.84 |
| 水通量 | STL 趋势残差 | 0.6448 | 0.4953 | 960.88 | 604.31 |
| 水通量 | 组合模型 | 0.6301 | 0.4857 | 921.06 | 593.84 |
| 沙通量 | 季节模板 | 1.4165 | 1.0935 | 13193.39 | 7529.11 |

对于水通量，组合模型权重选择为 `w_Q=1.00`，因此结果与季节模板一致，并优于单独 STL 模型。对于沙通量，组合模型 `RMSE_log=1.4132`，低于单独季节模板和单独 STL 模型，说明加入 `25%` STL 趋势残差修正确实改善了输沙预测。

## 13. 采样方案构建

采样方案的目标是：

```text
在控制采样总次数的前提下，尽可能覆盖高水沙通量、高变化率和高突变风险日期。
```

因此，先对未来每一天构造采样风险分数。风险分数由六部分组成：

```text
R_t =
0.35 × A_t
+ 0.10 × B_t
+ 0.25 × C_t
+ 0.15 × D_t
+ 0.10 × E_t
+ 0.05 × G_t
```

其中：

| 指标 | 含义 |
| --- | --- |
| `A_t` | 平水情景沙通量强度 |
| `B_t` | 偏丰情景沙通量强度 |
| `C_t` | 沙通量变化率 |
| `D_t` | 是否处于 7-9 月峰值期 |
| `E_t` | 是否处于 6-10 月汛期 |
| `G_t` | 历史突变月份风险 |

连续变量先归一化到 `[0,1]`。沙通量变化率定义为：

```text
C_t = |ln(1 + F_hat_t) - ln(1 + F_hat_{t-1})|
```

采样基础频率为：

| 时段 | 水沙特征 | 基础采样策略 |
| --- | --- | --- |
| 1-3 月 | 枯水期，水沙通量较低 | 约每 10 天一次 |
| 4-5 月 | 入汛前，通量逐渐上升 | 约每 5 天一次 |
| 6-10 月 | 汛期，水沙输移集中 | 约每 2 天一次 |
| 11-12 月 | 退水期，通量降低 | 约每 7 天一次 |

在基础采样日期之外，每年再选取风险分数最高的日期及其前后相邻日期进行加密采样。这样既保证常规监测连续性，又能提高对洪峰、沙峰和突变过程的捕捉能力。

为了使采样计划能够真正落到执行层面，还需要确定每个采样日期的具体采样时刻。由于题目没有给出未来逐小时水沙过程，不能对未来某日精确预报洪峰出现的小时，因此采样时刻采用定性规则确定：普通时段取一天中相对稳定、便于统一执行的上午时刻；高风险时段增加午后和夜间采样，以捕捉洪峰、沙峰在一天内可能出现的变化。

具体设定如下：

| 采样等级 | 适用日期 | 采样时刻 | 定性依据 |
| --- | --- | --- | --- |
| `base_regular` | 枯水期、退水期和非汛期常规采样日 | `09:00` | 非汛期水沙日内变化较弱，上午固定时刻便于保持监测口径一致 |
| `flood_regular` | 6-10 月汛期常规采样日 | `08:00` | 汛期需较早获取当天水沙状态，便于当天判断是否需要追加监测 |
| `high` | 风险分数最高的高风险采样日 | `08:00`、`14:00`、`20:00` | 高风险日可能出现快速涨水、涨沙或退水变化，早、中、晚三次可覆盖日内变化过程 |

因此，本题的采样结果分为两个概念：

```text
采样日期：表示哪一天需要安排采样；
采样时次：表示该日期具体几点采样，高风险日一天包含多个时次。
```

原采样日期表给出未来两年哪些日期需要监测；新增采样时刻表进一步给出每一次采样的具体日期和小时。

## 16. 结论

问题三最终采用 STL-季节模板交叉验证加权组合模型。模型以问题二得到的日尺度水沙通量序列为基础，先分别建立近期加权季节模板模型和 STL 趋势残差模型，再通过留一年交叉验证确定组合权重。验证结果显示，组合模型较单独 STL 模型误差更低，尤其对沙通量预测更优。

平水情景下，预测 2022 年年径流量为 `441.88 亿 m^3`，年输沙量为 `30097.64 万吨`；预测 2023 年年径流量为 `464.54 亿 m^3`，年输沙量为 `32225.59 万吨`。未来两年水沙通量仍表现出明显汛期集中性，6-10 月为主要水沙输移期，7-9 月为高风险监测时段。

据此制定的采样方案建议每年设置约 `120` 个采样日期，枯水期低频、入汛前中频、汛期高频，并在高风险日期前后加密。进一步落实到具体时刻后，普通日期一天采样一次，高风险日期在 `08:00`、`14:00`、`20:00` 三个时刻采样；对应实际采样时次为 2022 年 `172` 次、2023 年 `174` 次。该方案能够在控制监测成本的同时，提高对高输沙和突变过程的捕捉能力。
