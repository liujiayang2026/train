# Route r01-interpolated-daily-pattern

- 对应问题：q2
- 过程状态：candidate
- 要回答的内容：分析2016—2021年水沙通量的突变性、季节性、周期性和汛期集中程度。
- 输入与数据口径：通过命令行显式读取 q1 某次运行的 `cleaned_hydro_timeseries.csv`。基准口径将流量、含沙量和原时刻沙通量线性插值到逐小时网格，再聚合为日序列；另以“插值分量后相乘”和“前值保持”作敏感性对照。
- 核心模型/算法：日序列聚合、月度/年度集中度、前后滑动窗突变评分、阈值筛选与事件去簇、周期图和典型滞后自相关。
- 关键公式位置：notes/question2-method.md。
- 代码入口：code/analyze_question2.py。
- 关联运行：`runs/run-20260809-0000-imported-legacy/`（历史导入，partial）；`runs/run-20260809-1940-canonical-sensitivity/`（基于历史 q1 输出的成功路径复现）；`runs/run-20260809-1954-canonical-q1-input/`（绑定 q1 1941 run 的成功证据）；`runs/run-20260809-2036-time-block-q1/`（绑定 q1 2032 连续时间块成功 run 的当前复现证据）。
- 与其他问题/路线的关系：依赖q1清洗输出，其日序列和突变月份曾被q3历史路线使用。
- 当前优点：所有机器结果归属同一 run；同时输出插值口径、突变窗口/阈值/事件间隔、时间子区间的稳健性证据；绝对流量与绝对沙通量分图展示，单位不混用。
- 已知缺陷或冲突：长区间双向插值可能平滑稀疏含沙量与沙峰；沙通量继承 q1 补值误差；突变事件只是算法候选，缺少外部调度记录时不能作因果归因；六年样本不足以证明长期稳定周期；不宜直接作为无泄漏预测标签。
- 放弃时的原因：不适用；当前作为候选路线保留。
