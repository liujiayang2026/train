# Question 1

This folder contains the pricing-pattern and task non-completion analysis.

- `code/question1_complete.py`: original descriptive statistics and four
  spatial maps.
- `code/question1-quantitative-causes.py`: multivariable cause analysis,
  bootstrap intervals, city residuals, and population/traffic comparison.
- `data/processed/question1-cause-indicators.csv`: task-level derived
  indicators for all 835 tasks.
- `results/`: grouped statistics, adjusted odds ratios, model metrics, and city
  comparisons.
- `figures/`: descriptive maps and quantitative diagnostic figures.
- `docs/quantitative-cause-analysis.md`: revised interpretation and paper-ready
  conclusions.
- `docs/external-data-sources.md`: public 2017 population and traffic sources.

Run the two scripts from the project `B` folder. Original attachments are read
from the project folder and are never overwritten.
