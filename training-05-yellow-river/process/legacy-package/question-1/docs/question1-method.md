# 问题一完整建模思路

## 1. 问题理解

问题一要求研究该水文站黄河水的含沙量与时间、水位、流量之间的关系，并估算 2016-2021 年每一年的年总水流量和年总排沙量。

记：

- `C(t)` 为含沙量，单位为 `kg/m^3`；
- `Q(t)` 为流量，单位为 `m^3/s`；
- `H(t)` 为水位，单位为 `m`；
- `t` 为观测时间。

附件 1 中水位和流量数据基本完整，但含沙量缺失较多。因此本题不能只用已有含沙量观测值直接积分，否则会遗漏大量时段。整体思路是：

1. 先清洗并统一时间序列；
2. 用有实测含沙量的数据建立含沙量关系模型；
3. 用模型预测缺失时刻的含沙量；
4. 形成完整的含沙量序列；
5. 对流量和排沙率进行时间积分，得到年总水量和年总排沙量。

## 2. 数据预处理

附件 1 按年份分为 2016-2021 年六个 sheet。每个 sheet 中，“年、月、日”通常只在一天开始处填写，后续行为空白，因此需要向下补齐日期信息。

对每条记录整理为：

```text
(t_i, H_i, Q_i, C_i)
```

其中 `C_i` 可能为空。

具体处理如下：

1. 将“年、月、日”空白单元格向下补齐；
2. 将时间字段转化为标准日期时间；
3. 对 `24:00` 这类记录，转化为次日 `00:00`；
4. 若存在重复时刻，则对同一时刻的数值取平均；
5. 水位和流量作为连续变量保留；
6. 少量水位缺失用时间插值补齐；
7. 含沙量缺失比例较大，不直接做时间插值，而是通过模型预测。

之所以不直接对含沙量做普通插值，是因为含沙量在汛期变化剧烈，简单插值容易低估峰值或平滑掉突变。

## 3. 初步关系分析

先只使用有实测含沙量的记录，计算含沙量与流量、水位的相关性。结果为：

```text
corr(C, Q) ≈ 0.624
corr(C, H) ≈ 0.615
corr(ln C, ln Q) ≈ 0.890
```

可以看出：

1. 含沙量与流量呈明显正相关；
2. 含沙量与水位也呈明显正相关；
3. 取对数后，`ln C` 与 `ln Q` 的线性关系更强。

这说明流量是解释含沙量变化的重要变量，水位也能提供额外解释信息。同时，月份统计显示含沙量具有明显季节性：1-5 月较低，6-10 月明显升高，7 月最突出。

## 4. 对含沙量取对数

含沙量 `C` 始终为正，并且在汛期会出现很高峰值，数据分布右偏明显。如果直接拟合 `C`，极端高值会强烈影响模型。

因此令：

```text
Y = ln C
```

把模型写成：

```text
ln C = f(Q, H, t) + ε
```

这样做有三个好处：

1. 预测值还原后一定为正；
2. 能减弱极端含沙量峰值对拟合的支配；
3. 符合水沙关系中常见的幂律形式。

例如，若只考虑流量，常见关系可写为：

```text
C = a Q^b
```

两边取对数后得到：

```text
ln C = ln a + b ln Q
```

因此 `ln Q` 是模型中的核心解释变量。

## 5. 候选模型设置

为了判断时间、水位、流量各自的解释作用，我设置了四类候选模型。

### 5.1 仅时间模型

该模型只考虑长期趋势和季节周期：

```text
ln C = β0
     + β1 T
     + β2 sin(2πd)
     + β3 cos(2πd)
     + β4 sin(4πd)
     + β5 cos(4πd)
     + ε
```

其中：

```text
T = 距 2016-01-01 的年份数
d = 年内时间比例
```

`sin(2πd)` 和 `cos(2πd)` 描述一年周期，`sin(4πd)` 和 `cos(4πd)` 描述半年周期。

### 5.2 二次水动力模型

该模型只考虑流量和水位：

```text
ln C = β0
     + β1 ln Q
     + β2 H
     + β3 (ln Q)^2
     + β4 H^2
     + β5 (ln Q)H
     + ε
```

其中二次项用于刻画非线性关系，交互项 `(ln Q)H` 表示流量作用可能受到水位条件影响。

### 5.3 水动力-时间综合模型

该模型同时包含二次水动力变量和时间周期变量，即在 5.2 的基础上加入：

```text
T, sin(2πd), cos(2πd), sin(4πd), cos(4πd)
```

### 5.4 简化综合模型

该模型保留主要变量，但不加入二次项和半年周期：

```text
ln C = β0
     + β1 T
     + β2 sin(2πd)
     + β3 cos(2πd)
     + β4 ln Q
     + β5 H
     + ε
```

## 6. 模型比较方法

模型比较采用“留一年交叉验证”。

附件 1 覆盖 2016-2021 年共六年。每次选取其中一年作为验证集，其余五年作为训练集。例如：

```text
用 2017-2021 年训练，验证 2016 年；
用 2016、2018-2021 年训练，验证 2017 年；
……
用 2016-2020 年训练，验证 2021 年。
```

每个候选模型都重复上述过程 6 次，最后取平均验证误差。

主要评价指标为：

```text
RMSE_log = sqrt(mean((ln C_obs - ln C_pred)^2))
```

同时记录：

```text
MAE_log
R^2_log
RMSE_kgm3
MAE_kgm3
```

排序时优先使用 `RMSE_log`，因为模型本身拟合的是 `ln C`，而且 log 尺度能避免少数极端汛期值完全主导误差。

平均验证结果为：

```text
hydro_only_quadratic: RMSE_log = 0.4637, R^2_log = 0.6633
hydro_time_harmonic : RMSE_log = 0.4656, R^2_log = 0.6549
simple_hydro_time   : RMSE_log = 0.5433, R^2_log = 0.5216
time_only           : RMSE_log = 0.9484, R^2_log = -0.7665
```

为进一步检验模型阶数和函数形式是否合适，又补充比较了指数型模型以及三次、四次高阶水动力模型。扩展比较结果如下：

| 模型 | 特征数 | 平均 RMSE_log | 平均 R^2_log |
| --- | ---: | ---: | ---: |
| 二次水动力模型 | 5 | 0.4637 | 0.6633 |
| 二次水动力模型 + 时间项 | 10 | 0.4656 | 0.6549 |
| 三次水动力模型 + 时间项 | 14 | 0.4870 | 0.6011 |
| 三次水动力模型 | 9 | 0.5045 | 0.5287 |
| 一次 `ln Q, H` 模型 | 2 | 0.5076 | 0.5837 |
| 幂函数 `ln Q` 模型 | 1 | 0.5130 | 0.5881 |
| 四次水动力模型 | 14 | 0.5829 | 0.1726 |
| 指数型 `Q, H` 模型 | 2 | 0.7617 | -0.0142 |
| 仅时间模型 | 5 | 0.9484 | -0.7665 |

因此，验证误差最小的是二次水动力模型 `hydro_only_quadratic`。指数型模型对高流量样本较敏感，高阶多项式模型的泛化误差反而增大，说明继续提高阶数会带来过拟合风险。

从模型比较结果可以进一步得到以下判断：

1. `time_only` 模型的 `RMSE_log` 最大，且 `R^2_log` 为负，说明仅靠年份趋势和周期项无法有效解释含沙量变化。黄河含沙量不是单纯随月份周期平滑变化，而是与具体水动力过程密切相关。
2. `hydro_only_quadratic` 模型误差最小，说明流量和水位是含沙量变化的主要驱动因素。尤其 `ln C` 与 `ln Q` 的相关性较强，表明流量对泥沙输移能力具有决定性影响。
3. `hydro_time_harmonic` 模型在加入时间趋势和季节谐波后，验证误差没有下降，反而略高于二次水动力模型。这说明显式时间变量带来的额外信息有限，容易引入轻微过拟合。

因此，虽然含沙量存在明显季节性，但这种季节性主要已经通过流量和水位的季节变化体现出来。也就是说，时间因素并非没有影响，而是其影响大部分被 `Q` 和 `H` 吸收。最终选择 `hydro_only_quadratic`，既能保持较低验证误差，又具有更清晰的水动力解释。

## 7. 最终含沙量模型

最终采用：

```text
ln C = β0
     + β1 ln Q
     + β2 H
     + β3 (ln Q)^2
     + β4 H^2
     + β5 (ln Q)H
     + ε
```

该模型可以表达：

1. 含沙量随流量变化的非线性关系；
2. 含沙量随水位变化的非线性关系；
3. 流量和水位之间的交互作用。

## 8. 系数估计

模型系数不是人工设定的，而是由实测数据通过最小二乘法估计。

只选取含沙量不缺失的记录作为训练样本。对第 `i` 条样本：

```text
Y_i = ln C_i
```

解释变量向量为：

```text
X_i = [1, ln Q_i, H_i, (ln Q_i)^2, H_i^2, (ln Q_i)H_i]
```

于是所有样本可以写成矩阵形式：

```text
Y = Xβ + ε
```

最小二乘法的目标是让所有样本的预测误差平方和最小：

```text
min ||Y - Xβ||^2
```

理论解为：

```text
β_hat = (X^T X)^(-1) X^T Y
```

实际程序中使用 `numpy.linalg.lstsq` 求解，它与最小二乘思想一致，但数值上更稳定。

为了避免 `H`、`H^2`、`ln Q`、`(ln Q)^2` 等变量尺度差异过大，在拟合前对每个解释变量做标准化：

```text
Z_j = (X_j - mean_j) / std_j
```

预测时也使用相同的标准化参数。

## 9. 缺失含沙量补全

得到最终模型后，对每个缺失含沙量的时刻，根据当时的流量和水位预测：

```text
ln C_pred,i = X_i β_hat
```

再还原为含沙量：

```text
C_pred,i = exp(ln C_pred,i)
```

由于对数模型直接指数还原可能存在低估偏差，因此加入 smearing 修正：

```text
C_pred,i = exp(ln C_pred,i) × mean(exp(e_i))
```

其中：

```text
e_i = ln C_i - ln C_pred,i
```

最终用于积分的含沙量定义为：

```text
C_used(t_i) =
    C_obs(t_i),  若该时刻有实测含沙量
    C_pred(t_i), 若该时刻含沙量缺失
```

这样既保留了真实观测，又避免了含沙量缺失导致排沙量无法计算。

## 10. 年总水流量计算

年总水流量是流量对时间的积分：

```text
W_y = ∫_year Q(t) dt
```

离散观测下采用梯形积分：

```text
W_y ≈ Σ 0.5 × (Q_i + Q_{i+1}) × Δt_i
```

其中 `Δt_i` 以秒为单位，`Q` 的单位为 `m^3/s`，所以 `W_y` 的单位为 `m^3`。最后换算为 `10^8 m^3`。

## 11. 年总排沙量计算

瞬时排沙率定义为：

```text
S(t) = Q(t) C_used(t)
```

单位为：

```text
(m^3/s) × (kg/m^3) = kg/s
```

年总排沙量为：

```text
M_y = ∫_year Q(t) C_used(t) dt
```

离散形式为：

```text
M_y ≈ Σ 0.5 × [Q_i C_i + Q_{i+1} C_{i+1}] × Δt_i
```

结果先得到 `kg`，再换算为 `t` 和 `10^4 t`。

## 12. 结果解释

根据建模与验证结果，可得：

1. 含沙量与流量、水位均呈显著正相关；
2. `ln C` 与 `ln Q` 的关系尤其明显，说明流量是主要解释变量；
3. 水位提供额外解释能力；
4. 二次项和交互项说明水沙关系不是简单线性关系；
5. 含沙量具有明显季节性，高值主要集中在 6-10 月，尤其是 7 月；
6. 但显式加入时间周期项后预测效果没有提升，说明季节性主要通过流量和水位变化间接体现；
7. 因此采用二次水动力模型补全含沙量，并据此估算年总水流量和年总排沙量。

最终可以在论文中概括为：

```text
该水文站含沙量主要受流量和水位控制，其中流量影响最显著。含沙量存在明显汛期高值特征，但季节效应大部分通过流量、水位的变化反映。基于留一年交叉验证，二次水动力模型具有最小预测误差，因此用于补全缺失含沙量并计算年总排沙量。
```
