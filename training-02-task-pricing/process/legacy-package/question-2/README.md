# Question 2 File Guide

This folder contains the pricing-model work for Project 2, Problem B,
Question 2.

## Folder Layout

- `docs/`: modeling notes, paper outline, and text summaries.
- `code/`: reusable Python scripts.
- `results/`: CSV outputs and task-level pricing tables.
- `figures/`: generated comparison charts.

## Main Scripts

- `code/baseline-pricing.py`: builds spatial features, fits the monotone
  Logistic completion model, and outputs baseline/improved pricing results.
- `code/scenario-analysis.py`: compares budget and maximum price-change
  scenarios.
- `code/milp-pricing.py`: solves exact and practical MILP pricing models.

The final recommended Question 2 implementation scheme is the practical MILP
result generated by `code/milp-pricing.py`. Its task-level prices are saved in
`results/milp-pricing-results.csv`, and the overall comparison is saved in
`results/milp-comparison.csv`.
