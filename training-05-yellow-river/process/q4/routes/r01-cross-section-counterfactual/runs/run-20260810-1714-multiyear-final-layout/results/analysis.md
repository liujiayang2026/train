# 2016—2023年调水调沙实际效果的分级评价

## 跨附件校验

2019年近同期断面去除平均高程偏差后RMSE为0.109 m，1 m规则判定为通过。因此2018年仅按C级跨附件证据解释，并同时保留其校准限制。

## 本断面河床结果

- 2016年（B级，2016-06-08→2016-10-20）：内部稳健区净变化-91.7 m²，表现为冲刷；过流面积代理变化+91.7 m²。
- 2017年（B级，2017-05-11→2017-09-05）：内部稳健区净变化+328.0 m²，表现为淤积；过流面积代理变化-328.0 m²。
- 2018年（C级，2018-04-04→2018-09-13）：内部稳健区净变化+161.6 m²，表现为淤积；过流面积代理变化-161.6 m²；该数值仅对应1965—2050 m共同覆盖区，不能与其余年份按面积大小直接比较。
- 2019年（B级，2019-04-13→2019-10-15）：内部稳健区净变化-25.5 m²，表现为冲刷；过流面积代理变化+25.5 m²。
- 2020年（A级，2020-04-17→2020-07-29）：内部稳健区净变化+72.2 m²，表现为淤积；过流面积代理变化-72.2 m²；7月首末测次净变化+35.9 m²。
- 2021年（A级，2021-04-16→2021-07-22）：内部稳健区净变化+92.1 m²，表现为淤积；过流面积代理变化-92.1 m²；7月首末测次净变化+102.4 m²。
- 2022年（A*级，2022-04-18→2022-07-23）：内部稳健区净变化+31.0 m²，表现为淤积；过流面积代理变化-31.0 m²；7月首末测次净变化-169.9 m²。

PCHIP与分段线性在7个年度内部稳健区的净冲淤方向一致率为100%。

## 水沙和流速

- 2016年6—7月：平均流量691 m³/s，峰值1520 m³/s，插值累计过沙量6.24 Mt，含沙观测日覆盖率100.0%。
- 2017年6—7月：平均流量568 m³/s，峰值823 m³/s，插值累计过沙量3.28 Mt，含沙观测日覆盖率100.0%。
- 2018年6—7月：平均流量2014 m³/s，峰值3900 m³/s，插值累计过沙量145.67 Mt，含沙观测日覆盖率100.0%。
- 2019年6—7月：平均流量2327 m³/s，峰值3770 m³/s，插值累计过沙量134.32 Mt，含沙观测日覆盖率100.0%。
- 2020年6—7月：平均流量2247 m³/s，峰值4970 m³/s，插值累计过沙量118.61 Mt，含沙观测日覆盖率100.0%。
- 2021年6—7月：平均流量2107 m³/s，峰值4240 m³/s，插值累计过沙量68.35 Mt，含沙观测日覆盖率100.0%。
- 2020年4月→7月末面积加权流速变化+31.2%。
- 2021年4月→7月末面积加权流速变化+91.3%。
- 2022年4月→7月末面积加权流速变化+50.9%。

## 评价结论

国家调水调沙目标是多目标体系。本题单测站能够确认2020—2022年水动力均明显增强，但本断面减淤响应不稳定。其中2022年7月事件内部出现强冲刷，但尚未逆转4月至7月的累计淤积，因此评价为局部减淤目标部分达成；对B/C级年份只能说明含调水调沙季在内的阶段性净冲淤，不能把宽窗口全部归因于工程。2023年缺少6—7月后测次，不能评价。该结论不代表水库排沙、全河段减淤、输沙入海或河口生态补水的总体成效。

逐年目标达成与证据限制见 `target_achievement_matrix.csv`。
