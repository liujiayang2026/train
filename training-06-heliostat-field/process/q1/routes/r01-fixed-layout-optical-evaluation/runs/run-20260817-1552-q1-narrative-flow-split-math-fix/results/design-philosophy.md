# 因果留白

信息不再依靠同时出现来证明完整，而以一次只推进一个判断的节奏建立可信度。每个画面拥有明确边界：输入只呈现可观测条件，方法只呈现变换关系，汇总只呈现数据去向。空间中的留白不是空缺，而是让因果关系被准确辨认的必要间隔。

形式由克制的几何秩序构成。圆形承载太阳和场域，直线承担方向与传递，重复的小尺度标记形成计算节律。所有对齐、线宽与间距都应经过细密校准，使作品呈现出顶尖制图者反复推敲后的专业精度，而不是模板化流程组件的简单排列。

颜色只承担稳定语义：太阳黄表示外部输入，光学蓝表示计算主线，绿色表示保留的有效能量，红橙紫表示不同损失。颜色不装饰结论，也不替代图注；它以经过耐心校准的对比度，使读者在缩印和远观时仍能追踪信息流向。

文字被压缩为对象、动作、单位和口径。数字必须来自真实输入或正式输出，示意关系必须被明确标记为方法而非结果。字体、基线和符号以大师级制图的耐心统一，让每个标签都像测量标记一样可靠，同时给图形保留足够呼吸空间。

三张图彼此衔接但不互相替代：第一张建立世界，第二张解释机制，第三张说明归档方式。整体品质来自无数次微小校正形成的一致性；任何审美决定都必须服从物理正确、数据可追溯和论文语义准确。
