2017年CUMCM B题“拍照赚钱”的任务定价
问题二论文写作思路

说明：

本文档用于指导问题二正式论文撰写，不是程序运行说明。

问题二最终推荐方案采用：

单调Logistic完成概率模型
+ 多选择背包MILP
+ 预计支付成本约束
+ 价格调整惩罚
+ 区域服务水平约束。

贪心算法作为快速求解方法，精确MILP作为最优性验证，实用MILP作为最终实施方案。


一、问题二在全文中的作用

问题一已经得到以下结论：

1. 历史任务完成率为62.51%；

2. 未完成任务主要集中在深圳及广州部分任务密集区域；

3. 大量未完成任务属于65～69.5元的低价区间；

4. 原定价模型高估了会员密集区域的有效供给；

5. 任务价格、区域执行难度和任务竞争共同影响完成状态。

问题二应当承接问题一的结论，回答：

在任务位置和会员环境已经确定的情况下，如何重新配置各任务价格，使平台在控制预计支付成本的同时提高任务完成率？

本问不能简单采用统一加价，因为：

不同任务对价格的敏感程度不同；
部分任务加价后完成概率提升明显；
部分困难任务即使大幅加价也难以完成；
部分高完成率区域存在适当降价空间；
平台需要控制实际或预计支付成本。

因此，将问题二表述为：

“有限预计支付成本约束下，以任务预计完成数最大化为目标的离散定价优化问题。”

三、5.1问题分析写作思路

第一段：承接问题一

指出问题一发现原定价方案虽然具有空间差异性，但在深圳、广州等任务密集区域出现系统性低价，导致未完成任务在空间上聚集。

第二段：说明统一调价不可行

不同任务面临的会员供给、周边竞争和区域环境不同。如果对所有任务统一加价，会把大量成本投入本来已经容易完成的任务；如果只给历史未完成任务加价，又会使用任务结果信息直接制定方案，缺少推广能力。

第三段：提出两阶段模型

第一阶段根据价格和空间供需特征估计任务完成概率；

第二阶段以预计完成任务数最大为目标，在预计支付金额、价格范围和调价稳定性约束下选择各任务价格。

可直接使用的论文表述：

“针对原方案中低价任务集中失败及区域供需错配问题，本文首先建立任务价格与完成概率之间的单调响应模型，随后将各任务的离散候选价格作为决策变量，构造有限预计支付成本下的多选择背包定价模型。为避免纯完成率最优方案产生过大的价格跳变，并防止局部高完成区域被过度降价，进一步引入价格调整惩罚和区域服务水平约束。”


四、5.2任务完成概率模型写作思路

5.2.1 空间距离计算

使用Haversine公式计算任务与会员、任务与任务之间的距离：

d_ij
= 2R arcsin{
sqrt[
sin²((φ_i-φ_j)/2)
+ cosφ_i cosφ_j sin²((λ_i-λ_j)/2)
]
}

其中：

R=6371 km；
φ为纬度；
λ为经度。


5.2.2 特征定义

建议在正文放置一个变量表。

表：问题二完成概率模型主要变量

符号        含义

P_i         任务i的价格

D_i         任务i到最近会员的距离

N_i         任务i周围2 km内会员数量

G_i         任务i周围2 km内其他任务数量

Q_i         周围2 km内会员预订限额之和

C_i         周围2 km内会员信誉值之和

R_ir        任务i是否属于空间区域r

Y_i         任务完成状态


由于会员数量、限额和信誉累计值呈右偏分布，对其采用：

ln(1+x)

变换，以减少极端值影响。


5.2.3 区域划分

将任务经纬度标准化后使用K-means划分为5个空间区域，用于吸收附件中没有直接给出的交通条件、商业环境和会员活跃程度等空间差异。

区域中心大致为：

区域0：广州中心及周边；
区域1：东莞及周边；
区域2：深圳及周边；
区域3：佛山及广州西南部；
区域4：广州北部。

论文中应说明：

城市名称只是根据聚类中心位置进行近似解释，模型实际使用的是空间聚类区域，不将其视为严格行政区划。


5.2.4 Logistic模型

定义任务完成概率：

p_i(P)
= Pr(Y_i=1 | P,X_i)

建立：

p_i(P)
= 1/{1+exp[-z_i(P)]}

其中：

z_i(P)
= β_0
+ β_1P
+ β_2D_i
+ β_3ln(1+N_i)
+ β_4ln(1+G_i)
+ β_5ln(1+Q_i)
+ β_6ln(1+C_i)
+ Σ_rγ_rR_ir

对价格系数设置：

β_1 ≥ 0

保证其他条件相同时，任务价格提高不会导致预测完成概率下降。

模型使用L2正则化抑制变量共线性和参数过度波动。


5.2.5 模型指标

当前计算结果：

样本数：835；
训练集AUC：0.7995；
训练集Brier得分：0.1732；
标准化价格系数：0.2430；
原方案预测完成数：522.00；
原方案预测完成率：62.52%；
历史实际完成率：62.51%。

论文中必须写清：

AUC和Brier得分目前属于训练样本上的初步检验；
正式最终稿应补充空间分块交叉验证；
新方案完成率属于模型预测结果，不是实际实施结果。


五、5.3新定价优化模型写作思路

5.3.1 成本定义

任务未完成时，平台通常不支付酬金。因此，主成本指标采用预计支付金额：

c_i(P)=Pp_i(P)

原方案预计支付金额：

C_0
= Σ_iP_ip_i(P_i)

计算得到：

C_0=36,444.28元

推荐方案允许预计支付金额最多增加15%：

C_max
=1.15C_0
=41,910.92元


5.3.2 候选价格

任务i的价格候选集合为：

Ω_i
= {
P：
65≤P≤85，
|P-P_i|≤8，
P以0.5元为步长
}


5.3.3 多选择背包决策变量

定义：

x_ik
=1，任务i选择候选价格P_ik；
x_ik
=0，任务i不选择候选价格P_ik。

每个任务只能选择一个价格：

Σ_kx_ik=1


5.3.4 完成率最优模型

首先构造纯完成率最大化模型：

max
Σ_iΣ_kp_ikx_ik

满足：

Σ_kx_ik=1

Σ_iΣ_kP_ikp_ikx_ik≤C_max

x_ik∈{0,1}

其中：

p_ik=p_i(P_ik)

该模型称为“精确MILP方案”。


六、5.3.5实用MILP改进

纯完成率最优方案中，557个任务达到相对原价±8元的调价边界，实施调整幅度偏大。

因此在目标函数中加入价格调整惩罚：

max
{
Σ_iΣ_kp_ikx_ik
- μΣ_iΣ_k[(P_ik-P_i)/8]²x_ik
}

取：

μ=0.015

平方惩罚会优先抑制大幅度调价。


七、区域服务水平约束

为防止模型为了提高总体完成率而过度降低某个高完成区域的价格，增加：

R_r,new
≥R_r,old-0.01

等价写成：

Σ_(i∈A_r)Σ_kp_ikx_ik
≥
Σ_(i∈A_r)p_i(P_i)
-0.01|A_r|

即任一区域的预测完成率最多下降1个百分点。

加入价格惩罚和区域约束后的模型称为“实用MILP方案”，作为问题二最终推荐方案。


八、5.4模型求解写作思路

5.4.1 边际效率算法

首先采用边际效率贪心算法获得快速解。

任务价格提高0.5元时：

完成概率增量：

Δp_i(P)
=p_i(P+0.5)-p_i(P)

预计成本增量：

Δc_i(P)
=(P+0.5)p_i(P+0.5)-Pp_i(P)

边际效率：

E_i(P)
=Δp_i(P)/Δc_i(P)

每次选择E_i最大的任务增加0.5元，直至达到预计成本上限。


5.4.2 精确MILP求解

使用HiGHS整数规划求解器求解多选择背包模型。

求解状态：

Optimal

相对最优间隙小于0.0001%。


5.4.3 贪心算法最优性验证

贪心方案预计完成数：

574.5378

精确MILP预计完成数：

574.5387

两者只相差：

0.0010个任务

预测完成率均约为：

68.81%

因此可以得出：

在当前单调Logistic价格响应和约束条件下，边际收益总体具有较好的递减结构，贪心算法已经非常接近全局最优。

这一部分是问题二较有价值的验证结论：不是只给出一种算法，而是用整数规划证明快速算法的结果几乎达到全局最优。

十四、5.6模型评价写作思路

优点一：考虑任务异质性

不同任务具有不同的空间供需环境和价格响应，新方案不是统一加价。


优点二：成本口径合理

以P×p(P)表示预计支付金额，比直接使用全部标价之和更符合任务完成后支付酬金的实际过程。


优点三：能够验证求解质量

用精确MILP证明贪心算法已经接近全局最优，避免只给出启发式结果而无法判断其质量。


优点四：兼顾实施稳定性

价格调整惩罚减少了大幅调价，区域服务约束防止模型过度牺牲高完成区域。


局限一：价格响应并非严格因果效应

每个历史任务只观察到一个价格，其他价格下的完成概率属于反事实预测。


局限二：模型指标目前是训练集结果

正式论文最终稿应增加空间分块交叉验证和概率校准。


局限三：任务共享会员资源

完成概率求和近似忽略了会员配额和任务之间的容量竞争。


局限四：区域划分具有一定人为性

K-means区域受聚类数和初始中心影响，可进一步采用连续空间平滑模型。


十五、敏感性分析写作思路

已经比较：

预计成本增幅：

0%、5%、10%、15%、20%

最大调价幅度：

±5元、±8元、±10元

主要结果：

成本不增加、±5元：

预测完成率63.54%

成本增加5%、±5元：

预测完成率65.32%

成本增加10%、±8元：

预测完成率67.36%

成本增加15%、±8元：

预测完成率68.81%左右

成本增加20%、±10元：

预测完成率70.50%

分析结论：

随着预计成本增加，完成率持续提高，但边际收益逐渐下降。预计成本从15%提高到20%时，完成率只增加约1.7个百分点，因此15%成本增幅是相对合理的折中点。


十六、5.7问题二结论建议文本

可直接用于论文的初稿：

“针对原定价方案中部分任务价格偏低及未完成任务空间聚集的问题，本文首先利用任务价格、会员供给、任务密度和区域特征建立带价格单调约束的Logistic完成概率模型。在此基础上，将每个任务的离散候选价格作为决策变量，以预计完成任务数最大为目标，构造预计支付成本不超过原方案115%的多选择背包定价模型。为减少大幅调价并维持各区域服务水平，进一步在目标函数中加入价格调整平方惩罚，同时限制任一区域预测完成率下降不超过1个百分点。”

“求解结果表明，边际效率贪心方案的预计完成数为574.5378个，而精确MILP全局最优解为574.5387个，两者仅相差0.001个任务，说明贪心算法已接近全局最优。加入价格稳定性和区域服务约束后，实用MILP方案的预测完成率为68.74%，较原方案的62.52%提高约6.22个百分点，预计增加完成任务51.96个；预计支付金额由36,444.28元提高至41,910.85元，增幅控制在15%以内。”

“与纯完成率最优方案相比，实用MILP仅损失约0.07个百分点的预测完成率，却将达到±8元调价边界的任务数由557个减少至433个，并将平均绝对调价幅度由6.56元降至6.07元。空间结果显示，新方案主要提高深圳、广州中心及佛山部分失败热点的价格，同时适当降低东莞高完成率区域的价格，实现了预计成本在区域间的重新配置。因此，实用MILP方案在预计完成率、平台成本、价格稳定性和区域服务公平性之间取得了更合理的平衡。”

十九、正式写作注意事项

1. 将所有“完成率提高”写成“预测完成率提高”；

2. 不把模型预测结果写成真实实施结果；

3. 不声称价格系数具有严格因果意义；

4. 正文重点解释为什么预计成本使用P×p(P)；

5. 说明贪心算法和精确MILP几乎一致，体现结果可信度；

6. 最终推荐实用MILP，而不是只追求最高完成率的精确MILP；

7. 把详细的逐任务新价格放在支撑材料中，正文只展示汇总表和空间图；

8. 在模型评价中主动说明空间验证和会员容量数据的限制；

9. 问题三需要在问题二单任务定价基础上引入任务打包，不要在问题二过度展开打包模型；

10. 摘要必须明确写出62.52%、68.74%、51.96个和15%四个关键结果。
