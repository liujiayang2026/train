# 度量之光

空间不是装饰，而是论证本身。每一条线都应来自同一套几何关系，每一个角度都能被复算；留白承担分隔尺度与概念的职责，使视线先读到结构，再读到符号。画面以克制的网格和清晰的方向组织信息，像一件经过反复校准的科学仪器。

颜色只表达物理角色：太阳黄代表入射能量，光学蓝代表理想传播，绿色代表被接收的能量，朱红代表逸散。色彩不用于装饰，也不制造无意义的层次。透明度、线宽和端点都经过细致推敲，让叠加关系保持可辨，呈现出由深厚专业经验打磨出的精确感。

尺度通过并置而不是混淆来表达。角度放大的局部视图负责解释不可见的小锥角，真实比例的主视图负责说明距离、镜面尺寸与接收器高度。两种尺度各自诚实，并用明确标记连接；任何视觉夸张都必须被声明，任何几何结论都不得由版面需要反推。

文字是稀少的坐标，不是补救图形的段落。标题、数值和短标签只在视觉关系已经成立后出现，使用安静的无衬线字体与等宽数字形成节奏。公式只保留决定物理正确性的最小集合，使画面像由顶尖制图者耗费大量时间完成，而不是把推导全文搬上画布。

最终作品应当经得起两种观看：远看时，能量从太阳到镜面再到接收器的路径一眼可见；近看时，每条边界射线、每个命中点和每项尺寸都严谨一致。所有对齐、间距与交点都体现耐心而精确的手工校准，让美感来自可验证的秩序。
