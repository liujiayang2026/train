2017年CUMCM B题“拍照赚钱”的任务定价
问题一分析思路

重要修订说明（2026-07-26）

原说明中的交通拥堵、停车难度和执行成本只属于原因假设，附件数据不能直接证明。现已补充任务级多变量Logistic模型、240次Bootstrap区间、行政城市对照，以及2017年城市人口和高德交通指标。定量结果与完整口径见docs/quantitative-cause-analysis.md。

最重要的定量结果是：深圳行政范围内161个任务的实际完成率为21.74%，而仅根据价格、会员、预订限额、任务密度和相对价格得到的模型期望完成率为48.95%，残余缺口为-27.21个百分点。这证明深圳存在附件变量无法解释的区域差异，但不能直接把缺口归因于拥堵。四城层面的拥堵延时指数与完成率Spearman相关系数为-0.40，人口密度与完成率相关系数为-0.20，且只有4个城市样本，因此只能作为背景佐证，不能作为因果证明。

一、问题目标

问题一要求完成两个任务：

1. 研究附件一中已结束项目的任务定价规律；
2. 结合任务位置、会员信息和任务完成状态，分析任务未完成的原因。

本问不能只比较价格和完成率，还需要把任务价格、任务空间分布、会员有效供给和任务之间的竞争关系结合起来。


二、数据说明

附件一共有835个历史任务，字段包括：

任务编号、任务GPS纬度、任务GPS经度、任务标价、任务执行情况。

其中：

已完成任务522个；
未完成任务313个；
总体完成率为62.51%；
任务价格范围为65～85元；
平均价格约69.11元；
价格中位数为67元。

附件二共有1877名会员，字段包括：

会员编号、会员位置、预订任务限额、预订开始时间、信誉值。


三、总体分析路线

问题一可以按照以下路线展开：

第一步：对任务价格和完成状态进行描述性统计；

第二步：将任务和会员经纬度接入地图，观察任务价格和未完成任务的空间聚集情况；

第三步：构造任务周围会员供给、任务密度、最近会员距离等空间指标；

第四步：建立原任务价格解释模型，分析平台原来的定价规律；

第五步：建立任务完成概率模型，识别未完成任务的主要影响因素；

第六步：结合地图、统计结果和模型结果，归纳原定价方案的不足。


四、描述性统计结论

按照任务价格分组，可以得到：

65～69.5元：510个任务，完成率约54.1%；
70～74.5元：207个任务，完成率约74.4%；
75～79.5元：78个任务，完成率约75.6%；
80～85元：40个任务，完成率约82.5%。

整体上，任务价格提高后，任务完成率明显上升。

完成任务的平均价格约为69.82元；
未完成任务的平均价格约为67.93元；
两者相差约1.89元。

这说明价格是影响任务完成的重要因素。尤其是任务价格由70元以下提高到70元以上时，完成率出现明显提升。

但是，价格和完成率之间的关系不能直接解释为简单因果关系，因为平台可能已经根据任务位置和任务难度对价格进行了调整。因此，还需要进行空间分析。


五、静态地图分析

将835个历史任务接入卫星地图，按照任务价格和执行状态绘制任务分布图。

地图编码方式如下：

蓝色：65～69.5元；
绿色：70～74.5元；
黄色：75～79.5元；
红色：80～85元；
圆点：任务已完成；
叉号：任务未完成。

地图揭示出以下规律：

1. 低价任务占据主体

地图上蓝色任务点数量最多，说明平台大量采用65～69.5元的低价。蓝色叉号也明显多于其他颜色的叉号，说明未完成任务主要来自最低价格区间。

2. 未完成任务具有空间聚集性

未完成任务并非在整个区域内随机分布，而是在深圳、广州部分区域形成明显的集中带。这说明任务失败不仅与任务自身价格有关，还与所属区域的交通、任务竞争和会员活动情况有关。

3. 深圳及其周边是明显的失败热点

深圳附近存在大量密集的蓝色叉号。该区域同时具有任务密度高、低价任务多和未完成任务集中的特点。

初步空间聚类结果显示，深圳附近约有198个任务，平均价格约68.30元，完成率约35.4%，明显低于总体完成率。

深圳区域人口和会员较多，但城市交通、停车、时间和出行成本也较高。原定价模型可能只注意到附近会员数量较多，从而降低了价格，却没有充分补偿实际执行成本。

4. 广州—佛山区域任务密集且完成情况分化

广州和佛山附近任务高度集中，低价任务较多，已完成和未完成任务相互混合。

这表明，在同一个区域内，会员会在多个相邻任务之间进行选择。价格较高、距离较近或路线更方便的任务会被优先领取，而相对吸引力较低的任务可能无人完成。

5. 东莞附近任务完成情况较好

东莞附近的圆点比例明显高于叉号。空间聚类结果显示，该区域的平均价格约70.08元，完成率约97.0%。

这说明在东莞附近，70元左右的价格基本能够覆盖会员的执行成本，局部供需关系相对合理。该区域可以作为后续重新定价时的参考区域。

6. 北部和外围任务虽然距离较远，但完成率不低

地图北部和外围任务比较稀疏，其中较多任务采用绿色、黄色或红色价格，并且以完成状态为主。

这说明距离远不是任务失败的充分条件。只要价格能够补偿额外的出行成本，偏远任务仍然可以顺利完成。


六、需要构造的空间变量

1. 任务与会员之间的距离

利用Haversine公式计算任务i和会员j之间的球面距离：

d_ij = 2R arcsin[ sqrt(sin²((纬度差)/2)
       + cos(任务纬度)cos(会员纬度)sin²((经度差)/2)) ]

其中R取地球平均半径6371 km。

2. 最近会员距离

D_i = min(d_ij)

表示任务i到最近会员的距离。

3. 周边会员数量

N_i(r) = Σ I(d_ij ≤ r)

可以分别计算任务周围1 km、2 km、5 km范围内的会员数量。

4. 有效会员供给

简单会员数量不能准确反映会员真正执行任务的能力，因此构造：

S_i = Σ I(d_ij ≤ r) × w_j × exp(-λd_ij)

其中w_j综合会员信誉值、预订限额和预订开始时间。

会员距离任务越近、信誉越高、可预订限额越大，对任务i的有效供给贡献越大。

5. 任务聚集度

G_i(r) = Σ(k≠i) I(d_ik ≤ r)

表示任务i周围r km内其他任务的数量。

6. 局部任务竞争强度

C_i = Σ(k≠i) I(d_ik ≤ r) exp[η(P_k-P_i)]

如果任务i附近存在较多价格更高的任务，则竞争强度增大，任务i更容易被会员放弃。


七、原任务定价规律分析

初步统计结果表明：

1. 周围会员越密集，平台原定价总体越低；
2. 任务位置越偏远，平台通常会给予一定价格补偿；
3. 任务较集中的区域，原价格略有下降；
4. 仅使用最近会员距离、2 km内会员数和1 km内任务数，可以解释约29%的价格差异；
5. 其中会员密度是最明显的空间定价因素。

因此，可以将原定价规律表示为：

P_i = β0 + β1D_i + β2S_i + β3G_i + β4R_i + ε_i

其中：

P_i为任务价格；
D_i为最近会员距离；
S_i为有效会员供给；
G_i为任务聚集度；
R_i为区域变量；
ε_i为未观测因素。

根据初步结果，平台可能采用了如下定价原则：

会员密集、任务集中、交通相对便利的区域采用较低价格；
会员较少、任务位置偏远的区域适当提高价格。

这一原则具有一定合理性，但存在明显的空间错配。


八、任务完成概率模型

将任务执行状态作为二元因变量：

Y_i = 1，表示任务完成；
Y_i = 0，表示任务未完成。

建立Logistic回归模型：

Pr(Y_i=1)
= 1 / {1 + exp[-(α0 + α1P_i + α2D_i + α3S_i
                 + α4G_i + α5C_i + α6R_i + α7P_iS_i)]}

其中：

P_i表示价格；
D_i表示最近会员距离；
S_i表示有效会员供给；
G_i表示任务聚集程度；
C_i表示相邻任务竞争强度；
R_i表示区域差异；
P_iS_i表示价格和会员供给的交互关系。

模型中预计：

价格系数α1为正，即价格越高，任务越容易完成；
竞争强度系数α5为负，即附近替代任务越多，任务越容易失败；
有效会员供给通常有利于任务完成，但其影响可能受到区域和价格的调节；
深圳等高成本区域可能具有显著的负向区域效应。


九、任务未完成的主要原因

1. 绝对价格偏低

65～69.5元任务的完成率只有54.1%。部分任务的标价不足以覆盖会员的交通、时间和执行成本。

会员选择任务时考虑的是净收益：

U_ij = P_i - C_distance(d_ij) - C_time - C_difficulty

当所有会员对任务i的净收益都低于接受阈值时，该任务就不会完成。

2. 原方案高估了会员密集区域的有效供给

深圳和广州附近虽然注册会员较多，但未完成任务也更加集中。

注册会员数量并不等于真正可以执行任务的会员数量。会员还受到预订开始时间、预订限额、信誉、当前任务占用和出行距离等限制。

3. 区域执行成本没有得到充分补偿

深圳、广州等城区的交通拥堵、停车和时间成本较高，但大量任务仍被设置在最低价格区间，造成系统性低价。

4. 任务之间存在竞争和选择替代

同一区域内同时出现多个任务时，会员会优先选择价格更高、距离更近或路线更方便的任务。低吸引力任务容易被剩余下来。

5. 原模型没有区分任务聚集的双重作用

任务聚集既可能产生便利效应，也可能产生竞争效应。

便利效应：多个任务可以顺路完成；
竞争效应：会员会在多个任务中进行选择。

在问题一的单任务发布条件下，竞争效应比较明显；在问题三的任务打包条件下，可以利用便利效应提高完成率。


十、问题一的核心结论

原任务定价具有明显的空间差异性。平台总体采用了“会员密集区域低价、会员稀疏或位置偏远区域高价”的定价策略。

但是，地图和统计结果表明，未完成任务主要集中在深圳及广州部分任务密集区域，而且大多属于65～69.5元的低价任务。外围任务虽然距离会员较远，但由于价格补偿较高，完成情况反而较好。

因此，任务未完成的根本原因并不是单纯的地理距离过大，而是原定价方案没有准确反映任务所面对的局部供需关系和相对吸引力。原模型高估了会员密集区域的有效劳动力供给，并忽略了任务之间的竞争、城市交通成本和区域执行难度，从而造成部分城区任务出现系统性低价和集中性失败。

（一）原因一：任务绝对价格偏低

对应地图：

但是，这一结果仍属于观察性关联。高价任务可能本身位于较偏远区域，平台已经根据位置进行了补偿。因此，需要结合后续会员供给和区域效应进一步解释。


（二）原因二：注册会员数量不能代表有效会员供给

对应地图：

cause-2-effective-supply-map.png

地图含义：

颜色表示每个任务周围2 km内的注册会员数量，圆点和叉号分别表示完成与未完成。重点观察会员高度密集区域中仍然存在的大量未完成任务。

统计证据：

2 km内有0～2名会员的任务共有252个，完成率为79.4%，平均价格为71.89元；
2 km内有3～5名会员的任务共有210个，完成率为68.6%，平均价格为70.00元；
2 km内有6～10名会员的任务共有182个，完成率为52.7%，平均价格为67.40元；
2 km内有11名及以上会员的任务共有191个，完成率为42.9%，平均价格为66.09元。

分析：

会员密集区域的完成率反而更低，但不能据此认为会员越多越不利于任务完成。地图和统计同时说明，平台很可能因为附近注册会员较多而系统性降低了任务价格：会员最密集组的平均价格只有66.09元，而会员最稀疏组的平均价格达到71.89元。

因此，真正的问题是平台将注册会员数量误当成了有效供给。会员是否能够实际执行任务还受到距离、信誉值、预订限额、开始预订时间以及已经领取的其他任务影响。会员多与低价同时出现，最终形成会员密集地区仍有大量任务未完成的空间现象。


（三）原因三：不同区域存在显著残余差异，具体机制待验证

对应地图：

任务级多变量模型进一步表明，加入城市固定效应后AUC由0.700提高到0.829，Brier分数由0.207下降到0.163，说明区域确实包含大量附件变量未能解释的信息。深圳行政范围的实际完成率比任务模型期望值低27.21个百分点。

这些区域差异可能来自交通拥堵、停车难度、商业网点类型、会员活跃程度和任务发布时间等未观测因素。2017年城市级交通数据表明深圳高峰拥堵延时指数为1.783，但广州为1.883且完成率显著高于深圳。因此，拥堵是值得进一步检验的候选机制，而不是当前数据已经证实的唯一原因。论文中应将其表述为“区域固定效应”或“区域综合执行条件”，不能把某一种具体成本写成已经被数据直接证明的原因。


（四）原因四：相邻任务之间存在竞争和选择替代

局部竞争强度同时考虑任务周围2 km内的其他任务数量及其相对价格。附近任务越多、其他任务价格相对越高，当前任务面临的竞争越强。颜色表示竞争强度，圆点和叉号表示完成状态。

竞争指标可写为：

C_i = Σ(k≠i) I(d_ik≤2 km) exp[(P_k-P_i)/5]

统计证据：

低竞争组共有180个任务，完成率为66.7%，平均价格为72.61元；
中低竞争组共有231个任务，完成率为62.3%，平均价格为70.04元；
中高竞争组共有215个任务，完成率为61.9%，平均价格为67.05元；
高竞争组共有209个任务，完成率为59.8%，平均价格为67.19元。

分析：

随着原局部竞争分组提高，未调整完成率总体由66.7%下降到59.8%。但在控制城市、价格、会员数量和任务密度后，相邻更高价任务占比每增加10个百分点的调整后优势比为1.012，95% Bootstrap区间为0.951～1.089，不能确认独立负向影响。因此，原分组结果应解释为混合关联，而不能写成竞争具有稳定的负向因果作用。

地图显示，高竞争任务集中在广州中心区域和深圳任务密集区，其中存在较多未完成叉号。会员在同一区域面对多个任务时，会优先选择价格更高、距离更近或路线更方便的任务，因此价格相对较低的任务会被剩余下来。

高竞争组的平均价格也明显低于低竞争组，说明任务竞争与低价存在叠加效应。后续完成概率模型中应同时加入价格、竞争强度及二者的交互项，避免把竞争效应全部错误归因于价格。


十四、四类原因的综合关系

四个原因不是相互独立的，而是形成一条连续的作用链：

会员和任务在城区集中
→ 平台判断任务容易被领取
→ 对会员密集区域设置较低价格
→ 同一区域的任务相互竞争
→ 城市综合执行成本没有得到充分补偿
→ 低吸引力任务集中未完成。

因此，问题一最终不能只写成“价格低导致未完成”，而应写成：

原定价方案以注册会员密度和地理位置为主要依据，但没有正确估计有效会员供给，也没有充分考虑局部任务竞争和区域综合执行成本，导致深圳及广州部分任务密集区域出现系统性低价，并最终形成未完成任务的空间聚集。
