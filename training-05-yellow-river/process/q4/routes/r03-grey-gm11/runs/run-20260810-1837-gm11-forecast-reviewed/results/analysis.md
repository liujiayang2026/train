# GM(1,1)无调水调沙十年预测

## 中心结果

年化修正GM(1,1)取平移常数3 m/年，在1820—2050 m共同区预测十年平均高程变化+280.80 m，净断面变化+58940.3 m²，正变化网格占比100.0%，判定为 `net_deposition_dominant`。

## 稳定性诊断

中心情景只有55.3%的坐标满足|a|<0.3的中长期适用经验条件，级比检验通过率为0.0%；最大局部十年变化达到1751.9 m。
用前三项预测第四项的回测RMSE为4.635 m/年，MAE为3.806 m/年，逐点方向一致率为87.2%；实际与预测净断面变化分别为+88.8和+944.1 m²。

## 平移常数敏感性

年化模型各可行情景的净断面变化为：c=2.5: -16473.2 m²；c=3: +58940.3 m²；c=4: +34956.3 m²；c=5: +27458.9 m²。
原文式未年化模型各可行情景的净断面变化为：c=1.5: +81679.3 m²；c=2: +39098.5 m²；c=3: +21559.4 m²。固定c=1因部分坐标平移后仍非正而不能覆盖完整断面。

## 结论

GM(1,1)的可行情景总体给出净淤积方向，与恒定自然速率模型的净冲刷方向相反；因此冲淤结论明显依赖预测模型。与此同时，十年幅度远超历史变化尺度且对平移常数高度敏感，说明该4项序列不满足可靠长期灰色外推的条件。GM结果可以作为论文中的敏感性/对照结果，但不宜直接把逐点2033高程作为可信主预测。

第四输入段2020-03-19至2021-03-14跨过6—7月，天然汛期和调水调沙贡献无法分离，这也是该路线不能被解释为纯自然演变预测的重要限制。
